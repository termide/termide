- **Switching projects no longer stalls.** Leaving a project with a git status panel ran its git commands on the interface thread, a pause of a few hundred milliseconds on every switch; a collapsed git status panel did the same on every file change. Its counts now come from a background refresh, and returning to the project uses what it found instead of running git again. A file manager returned to moments after it last read its folder no longer skips the changes it missed meanwhile: it reads them a moment later. Entering a project reopened at startup no longer waits, for seconds at a time, while each external agent's panel asks the agent to restore its session's model and settings: they are asked for in the background, model first, and a model or setting you pick meanwhile is the one that stays. Picking an external agent's model or setting no longer holds the interface either: it shows once the agent has taken it. The syntax highlighting of every language is also prepared in the background at startup, rather than on the first frame that draws a code block in an editor or an agent's chat.
