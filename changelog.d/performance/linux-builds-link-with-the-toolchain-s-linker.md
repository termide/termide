- **Linux builds link with the toolchain's own linker.** The repository no longer forces GNU `ld`: x86_64 links with rust-lld, rustc's default since 1.90, and other architectures with the system's `ld` as before. Linking the binary took about 6.4 s with GNU `ld` against 1.0 s with lld; for packagers building from source, the only difference is the linker on x86_64. The developer guide shows how to use mold.
