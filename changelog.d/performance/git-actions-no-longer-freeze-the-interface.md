- **Git actions no longer freeze the interface.** Stashing, popping, applying, dropping and renaming a stash, staging, unstaging and reverting a file from its details, and Revert all ran git on the interface thread, which stopped responding until git finished — for seconds in a large repository or on a slow disk. They run in the background now, as a commit does, with the same notice or error when they end and the git panels refreshed after them. The stash dropdown lists the stashes in the background too and opens when they come; pressing the button again before that cancels it, and a stash's details window opens once git has read them. Moving or relinking a project no longer waits for git to mend the links of its worktrees.
