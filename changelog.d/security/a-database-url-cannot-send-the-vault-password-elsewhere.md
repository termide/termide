- **A database URL can no longer send a vault password to another server.** PostgreSQL takes `?host=`, `?port=` and `?user=` from a URL's query over its address, while the vault fills in the password kept for the address: a bookmark showing `prod-db` could deliver that password to a host of its choosing. A PostgreSQL URL naming a server, port or login in its query is now refused; a Unix socket directory (`?host=/run/postgresql`) still works.
