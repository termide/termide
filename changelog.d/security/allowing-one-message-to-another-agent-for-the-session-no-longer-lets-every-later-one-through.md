- **Allowing one message to another agent for the session no longer lets every later one through.** The answer was kept as a rule for the message's kind, so every later `info`, `question` or `reply` went to any panel unasked, whatever it said. In `ask` mode each `send_message` now asks, shows whom it goes to and all it says, and offers no answer that outlasts it. See [Talking to other panels](doc/en/agent.md#talking-to-other-panels).
