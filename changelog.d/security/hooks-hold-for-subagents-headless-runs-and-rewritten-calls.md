- **Command hooks and the session's guards hold for subagents, headless runs and rewritten calls.** The hooks of `hooks.toml` did not run around the calls of a panel's subagents or of `termide --prompt`, so a guard hook could be got around by delegating the call; they now run there too. A subagent could also call a tool switched off in the Tools menu, and `/undo` did not restore the files it changed; it is now held to the panel's toolset, and its edits are kept for `/undo`. Arguments a hook rewrites go back through plan mode and the tools switched off in the session, which a rewrite approved by the hook used to skip. A hook that read nothing of a large tool result no longer holds the agent past its timeout. See [Hooks](doc/en/agent.md#hooks).
