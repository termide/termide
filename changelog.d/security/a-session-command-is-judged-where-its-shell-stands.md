- **A terminal session's command is judged where its shell stands.** A command run with `shell` and `session`, or typed at a session's prompt with `terminals`, was judged as if it ran in the project after an earlier `cd /etc` in that session had moved the shell: `cat passwd` there read `/etc/passwd` unasked. It now starts from the shell's real directory, and where that cannot be told a relative path asks.
