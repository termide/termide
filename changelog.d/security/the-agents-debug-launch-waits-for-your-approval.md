- **The agent's debug launch of a project command waits for your approval.** A command the project's `commands.toml` brings is shown, with what it runs, before it first runs from the menu or a key; the agent's `debug start` launched it without that question. It now opens the same question and tells the agent to start again once you have answered. The parameters of a `start` are now part of what is judged (`start debug-server port=9000`), so "Allow always" for one launch no longer lets the same command through with any values; they may be given as numbers and booleans as well as strings.
