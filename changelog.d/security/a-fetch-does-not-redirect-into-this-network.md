- **A fetch does not redirect into this machine or its network.** The agent's `fetch` asked before reaching a loopback, private or link-local address only when the URL it was given named one; a public page that redirected there was not asked about. Now a redirect to such an address is refused unless the fetch started there, and with Chrome a page that ended up there is not read. The agent's fetch without Chrome and a URL opened in a viewer panel now follow redirects at all: before, they showed the redirect's empty body.
