- **A project command's key leaves termide's own keys alone until approved.** A repository's `commands.toml` could bind an unapproved command to a key such as `Ctrl+S` or `F3`, and every press asked about the command instead of saving or searching. Until the command is approved, its key is bound only if no termide action uses it. The approval window now also shows the debugger's arguments, which can run commands of their own, and a changed parameter default asks again, since the agent starts a command on its defaults.
