- **An ACP agent's file requests pass the permission checks.** Codex and Gemini CLI read and write files through termide (`fs/read_text_file`, `fs/write_text_file`), and these requests were served unchecked: a read of `~/.ssh/id_rsa` or a write in plan mode went through. They now pass the checks of termide's `read` and `write`: a `deny` rule or plan mode refuses them, and a read outside the project or a write the mode asks about is asked about, unless you have just let the agent at that file on its own card.
