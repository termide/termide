- **An agent's fetch of this machine or a private network asks first.** In `plan` and `edit` a fetch ran unasked wherever it pointed, so a page the agent read could send it to `127.0.0.1`, a router or the cloud metadata address (`169.254.169.254`). Such an address, in any spelling a browser reads, `localhost`, a local-only domain or a name without a dot now asks. A redirect into such an address is refused unless the fetch started there, and with Chrome a page that ended up there is not read. The agent's fetch without Chrome and a URL opened in a viewer panel now follow redirects at all: before, they showed the redirect's empty body.
