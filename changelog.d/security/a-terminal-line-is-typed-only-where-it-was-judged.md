- **A line the agent types into a terminal goes only where it was judged.** `terminals send` judges a line as a `shell` command when the shell waits at its prompt, and as input to a program otherwise; the shell could get back to its prompt, or leave it, between the check and the typing, so a line approved as a program's input ran as a command. The send is now refused when the shell has moved since its check, and a prompt counts only once the shell has drawn it again after the agent's last input: bash and zsh mark it, and a line left open — an unclosed quote, a continuation prompt — is no longer taken for the prompt.
