- **A wrapper no longer hides a destructive command.** A quoted or escaped name (`\rm`), a wrapper (`command`, `exec`, `env`, `xargs`, `timeout`, `sudo`), git's own options (`git -C . push --force`) and `find -exec`/`find -delete` are now judged as the command they run: such a command is no longer offered "allow always" or "allow for this session", and in `auto` mode removing the root, the home or the project asks you however it is wrapped instead of going to the reviewer. A git command with global options is no longer offered the rule `git *`, which covered every push and clean, and `find` is no longer offered `find *`.
