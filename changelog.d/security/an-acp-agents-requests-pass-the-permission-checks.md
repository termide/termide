- **An ACP agent's requests pass the permission checks.** Codex and Gemini CLI read and write files through termide (`fs/read_text_file`, `fs/write_text_file`), and these requests were served unchecked: a read of `~/.ssh/id_rsa` or a write in plan mode went through. They now pass the checks of termide's `read` and `write`: a `deny` rule or plan mode refuses them, and a read outside the project or a write the mode asks about is asked about, unless you have just let the agent at that very file on its own card — a read you allowed no longer lets it write there, nor at any other file the call named. A search the agent asks about is judged as a `read` of the folder it searches, where plan mode used to refuse it, and a deletion or a move is refused by whatever would refuse editing one of its files, where none of these kinds matched a rule. A command the agent runs in another directory is judged there, not in the project, and a call is taken for termide's own tool, already judged, only when the adapter marks it so: one that merely names itself like it is judged as any other.
