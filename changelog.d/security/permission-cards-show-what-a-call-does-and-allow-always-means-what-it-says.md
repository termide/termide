- **Permission cards show what a call does, and "allow always" saves the rule it shows.** A card about an MCP tool showed one of its arguments and "allow always" saved a rule for that argument's value; it now shows them all and saves `"*" = "allow"` for the tool, as documented. A `task` card shows the job as well as the agent, and an answer for the session trusts that agent's jobs; a `fork` card shows the work the new panel takes up; a rule on a skill's name holds whatever arguments the call passes. In `auto`, "allow always" is no longer offered for a rule the mode would set aside: the answer lasts for the session. See [MCP servers](doc/en/agent.md#mcp-servers).
