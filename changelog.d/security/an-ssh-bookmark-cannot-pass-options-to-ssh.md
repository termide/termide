- **An SSH bookmark can no longer pass options to ssh.** A bookmark's address was split on spaces into the `ssh` command line, so one from a cloned repository's `.termide/bookmarks.toml` with a host such as `-oProxyCommand=…` ran a command when picked. The address is now parsed as `ssh://[user@]host[:port]` and handed to ssh after `--`; a user or host starting with `-` or holding spaces is refused. IPv6 addresses in brackets now work too.
