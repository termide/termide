- **rust-analyzer starts only in a workspace you trust.** It runs the code of the workspace it analyses — build scripts, proc macros, and whatever the workspace's `.cargo/config.toml`, `rust-toolchain.toml` or `rust-analyzer.toml` name — so opening a Rust file of a cloned repository ran that repository's code. Opening one in a workspace not trusted yet now asks first, No by default; the trust is kept with the project beside its approved commands, and "Restart language server" asks again after a No.
