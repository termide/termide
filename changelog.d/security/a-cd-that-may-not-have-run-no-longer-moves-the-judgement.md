- **A `cd` that may not have run no longer moves where commands are judged.** `cd nope; cat ../x` or `false && cd a; cat ../x` was judged as if the `cd` had succeeded, so a read outside the project passed for one inside. A `cd` into a missing directory, after `&&` or `||`, in a pipeline, in the background or inside a block now holds only for the commands chained to it with `&&`; a subshell's `cd` ends with the subshell.
