- **A paste in the terminal cannot run what it carries.** Text pasted into a terminal panel was always wrapped in bracketed-paste markers and passed on whole, so an Escape in the copied text could end the paste early and have the rest run as typed, and a program that had not asked for the markers got them as junk. Control characters other than Tab and line breaks are now dropped, the markers go only to a program that enabled bracketed paste, and without it a line break goes as Return, as in other terminals.
