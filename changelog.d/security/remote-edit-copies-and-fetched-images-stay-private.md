- **Local copies of remote files, fetched images and opened agent blocks stay private.** A remote file opened for editing was copied into a shared `termide-remote-edit` folder in the system temp directory, readable by other local users, and a fetched image was written to a fixed name there, through any symlink another user planted at it; a block of the agent chat opened in the viewer was written there under a new name each time, also through a planted symlink. All of them now go to a folder of your own under the temp directory (`termide-<uid>/`, owner-only, refused when it is a link or someone else's), the editing copy is readable by you alone, and an agent block opened again reuses its file.
