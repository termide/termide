- **Local copies of remote files and fetched images stay private.** A remote file opened for editing was copied into a shared `termide-remote-edit` folder in the system temp directory, readable by other local users, and a fetched image was written to a fixed name there, through any symlink another user planted at it. Both now go to a folder of your own under the temp directory (`termide-<uid>/`, owner-only, refused when it is a link or someone else's), and the editing copy is readable by you alone.
