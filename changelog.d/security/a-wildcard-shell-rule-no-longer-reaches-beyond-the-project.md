- **A wildcard shell rule no longer reaches beyond the project.** A rule such as `cat *`, which the permission card offers for a `cat` that writes a file, let any later `cat` through unasked, `cat ~/.ssh/id_rsa` and `cat x > ~/.zshrc` included; `cp *` or `rm *` likewise let `cp ~/.ssh/id_rsa .` and `rm -rf ../sibling` through. A read outside the project, a redirection writing there or to a path that cannot be seen beforehand, and any other command whose paths lead out of the project or that runs in a directory outside it now ask unless the rule names that place itself. The system's temporary directories count as inside for commands, and the words a program takes as data — an `awk` or `sed` program, a commit message, the host and remote command of `ssh` — are not taken for paths. A variable set earlier on the line is judged by its value.
