- **A wildcard shell rule no longer reaches beyond the project.** A rule such as `cat *`, which the permission card offers for a `cat` that writes a file, let any later `cat` through unasked, `cat ~/.ssh/id_rsa` and `cat x > ~/.zshrc` included. A look-only read outside the project, or a redirection writing there or to a path that cannot be seen beforehand, now asks unless the rule names that place itself.
