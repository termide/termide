- **A hook's `allow` no longer overrides your rules.** A `before_tool_call` hook that answered `{"decision": "allow"}` ran the call past everything after it: a `deny` rule, an `ask` rule and the question about an edit under `.git`. It now only spares the call the mode's question, as in Claude Code: a `deny` rule still refuses it, and an `ask` rule or an edit under `.git` still asks.
