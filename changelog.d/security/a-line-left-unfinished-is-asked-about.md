- **A command line left unfinished is asked about.** A line ending in an open quote, an open `$(`, a trailing `\`, `&&`, `||` or `|`, or a here-document without its end was judged by the part before it, so `ls "` passed as `ls` in plan mode while the shell, waiting for the rest, would run whatever came next. Such a line can no longer be read as a whole: it is asked about, and plan mode refuses it. A `>` or `<(` inside quotes no longer counts as a redirection, so `rg '->'` stays a look-only command.
