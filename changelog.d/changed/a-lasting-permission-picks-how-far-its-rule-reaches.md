- **A lasting permission picks how far its rule reaches.** "Allow for this session" and "Allow always" on a file or a single command no longer record only that exact path or command: a second step lists the file, up to three of its folders and the whole project (`./**`), or the command, its subcommand (`cargo build *`) or its program (`ls *`), with the folder or the broader command preselected. `edit` rules now cover `write` as well, so a folder allowed for edits takes new files too; an old `[ai.permissions.write]` table still counts.
