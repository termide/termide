- **`F1` opens help in a window, on the keys of the panel in focus.** Help (`F1` / `Alt+H`, **Options → Help**) is now a large window over the panels instead of a panel squeezed into the layout. It opens on the section of the panel it was called from, typing filters the keys and descriptions, `Tab` / `Shift+Tab` step between sections, and `F1` or `Esc` closes it. The help panel is gone: closing the last panel now leaves a file manager at the project root in its place. See [Help Window](doc/en/ui.md#help-window).
