- **AI → Sessions lists where sessions are, in every project and outside them.** The section showed only the current project's own sessions, so those of a directory inside it, outside any project or of a directory since moved were out of reach. It now lists each directory agents worked in, newest first, with the time of its newest session and how many it has dimmed before the path, and `✗` on one that is gone. `Enter` opens an agent panel there, whose banner lists the sessions to resume, rename or delete; on a gone directory it asks where it is now and carries the sessions there, with those of its subdirectories, the agent panels of saved layouts following them. `Delete` deletes all of a directory's sessions but those open in a panel.
