- **A fork of an external agent's session branches off the agent's own session.** When the agent can branch its sessions (ACP `session/fork`; Claude Code can), the copy made by `F5`, `/fork` or the agent's `fork` tool takes up a branch of the source's agent session instead of a new session told the whole conversation, so the copy starts on what the agent already has cached rather than paying for the conversation again. A focus goes to the agent's own `/compact <focus>` once it has started. A copy that cannot branch keeps the old way, now without the "not available for an external agent" notice it used to show for a focus.
