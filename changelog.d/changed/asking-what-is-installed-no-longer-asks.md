- **Asking what is installed no longer asks.** `printf` (without `-v`), `command -v`, `type`, `rustup show` and its `list` subcommands, `go version` and a bare `--version` of common tools (`node`, `python3`, `npm`, `uv`, `git`, …) are look-only commands that run without a card. `cargo --version` and `rustc --version` still ask: rustup runs the toolchain a project names. `cargo add` and `cargo remove`, which only edit the manifest, are no longer treated as destructive, so their card offers "Allow always".
