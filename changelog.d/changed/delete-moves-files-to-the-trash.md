- **`Delete` in the file manager moves files to the trash.** `Delete` / `F8` move the selection to the system trash (macOS Trash, the freedesktop.org trash, the Windows Recycle Bin) after a prompt that starts on Yes; the new `delete_permanently` action, `Shift+Delete` / `Shift+F8`, deletes for good after a prompt that starts on No. Remote locations have no trash: `Delete` deletes there for good and its prompt says so. See [File Manager](doc/en/file-manager.md).
