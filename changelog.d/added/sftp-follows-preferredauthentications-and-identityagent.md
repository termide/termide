- **SFTP follows `PreferredAuthentications` and `IdentityAgent`, and asks for a key's passphrase.** The SSH configuration now chooses how SFTP logs in: `PreferredAuthentications` leaves out keys or the password (a host without `password` reports a refused login instead of asking for one), and `IdentityAgent` picks the agent's socket or turns the agent off. An encrypted key the agent does not hold asks for its passphrase, from the password vault or the user, and the vault keeps it under the key's path for every server it opens.
