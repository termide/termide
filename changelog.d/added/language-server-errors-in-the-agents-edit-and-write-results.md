- **The agent sees the language server's errors after its edits.** After `edit` or `write`, the file's language server is told of the change and the errors it reports are added to the tool's result — only the new ones when the file's errors before the change are known, 20 at most, warnings left out. A file no editor has open is opened in its server for the check, the server started if need be; the result waits for it at most 5 seconds. Claude Code on termide's tools gets the same.
