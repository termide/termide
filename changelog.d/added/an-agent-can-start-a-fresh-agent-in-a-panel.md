- **An agent can start a fresh agent in a panel.** A `task` call with `panel` hands the task over in the background and shows it in an agent panel of its own beside the others, without taking the focus: the panel follows the task while it runs, then holds the delegate's session for you to go on with. Ask the agent for a new agent in a panel to start one with a clean context and a prompt of its writing; its answer still comes back to the agent that started it.
