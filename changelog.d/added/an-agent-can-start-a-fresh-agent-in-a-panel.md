- **An agent can start a fresh agent in a panel.** `start_session` with `show` `panel` hands the work over in the background and shows it in an agent panel of its own beside the others, without taking the focus: the panel follows the session while it runs, then holds it for you to go on with. Ask the agent for a new agent in a panel to start one with a clean context and a prompt of its writing; its answer still comes back to the agent that started it, unless it was started with `reply` `none`.
