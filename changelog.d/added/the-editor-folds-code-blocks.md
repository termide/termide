- **The editor folds code blocks.** `Alt+,` folds the innermost block around the cursor, and again the block around it; `Alt+.` or a click on the `▸` in the gutter opens it, and a folded line ends in `⋯ N lines`. **Fold all** and **Unfold all** are in the panel's `[≡]` menu (`fold_all`, `unfold_all` under `[editor.keybindings]`, no default key), and Vim mode has `za`, `zc`, `zo`, `zM` and `zR`. The blocks come from the language server's folding ranges, or from the indentation when there is none or it is too slow to answer (its late answer serves the next fold); the cursor steps over a fold and opens it when a search or a jump lands inside. See [Editor](doc/en/editor.md).
