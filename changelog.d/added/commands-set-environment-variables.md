- **Commands set environment variables.** A command in `commands.toml` takes `env = { RUST_LOG = "debug" }`, its values holding placeholders, for its build, its debugger and the program — the way to give a program under a debug adapter its environment, since no shell reads that command line. A project command's `env` is part of what its approval covers. Launches through a debug adapter now also get the directory's `direnv` environment, as background and report commands do.
