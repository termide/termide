- **Review the agent's changes in the diff panel.** `/changes` (or **Review changes** in the agent panel's menu) opens the git diff panel on what the agent changed since you last accepted, your own edits between requests left out. `Space` keeps a hunk or lines, `D` rejects them — they are undone in the working tree and the agent is told in its next request — `U` takes the last rejection back, `A` and `X` keep or reject everything; staging or committing a change keeps it too. Each request snapshots the working tree into git trees no log shows, so shell commands and external agents (Claude Code, Codex, Gemini CLI) are covered as well. A file you edited too is marked and never rejected unasked. See [UI](doc/en/ui.md) and [Agent](doc/en/agent.md).
