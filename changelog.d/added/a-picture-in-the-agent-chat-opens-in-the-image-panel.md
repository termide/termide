- **A picture in the agent chat opens in the image panel.** A second click on a picture in the picked block opens it in the image panel, and `Alt`+click opens it at once in the system's image viewer, as in the file manager. With the block picked, `o` opens its first picture in the image panel instead of the call's text, and `O` opens it outside; `O` also opens a page the agent wrote outside. A picture `read` returned from a file opens as that file; a pasted one, or one sent by an MCP tool or an external agent, is written to a temporary file first.
