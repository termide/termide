- **A picture in the agent chat opens in the image panel.** A second click on a picture in the picked block opens it in the image panel, and `Alt`+click opens it at once in the system's image viewer, as in the file manager. With the block picked, `o` opens its first picture in the image panel instead of the call's text, and `O` opens it outside; `O` also opens a page the agent wrote outside. A picture `read` returned from a file opens as that file; a pasted one, or one sent by an MCP tool or an external agent, is written first to a file of its own in your private temp folder (`termide-<uid>/pictures/`), one per picture however often you open it, named by the image format its bytes are in — never by the type the agent claimed, so what is not a PNG, JPEG, GIF, WebP, BMP, ICO or TIFF image opens as a `.png` in an image viewer, not as a page or script.
