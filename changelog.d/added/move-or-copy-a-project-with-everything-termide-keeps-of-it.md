- **Move or copy a project with everything Termide keeps of it.** `F6` on a project in the `Projects` menu or on its selected menu-bar button moves the project's directory, and `F5` copies it. Its saved layout, unsaved buffers, agent sessions with their checkpoints and breakpoints go along, and a move also takes the permissions granted to it. The files go through a background operation. An open project closes for the move and opens again at the new path. A copy opens in the background beside the original, with its own session ids and no permissions granted. The current project's button now ends with `≡`, which opens its menu: Move, Copy, Change root path and Close. The button is shown even when only one project is open.
