- **`Ctrl+O` folds everything in the git diff and git status panels.** As in the agent panel, the key folds every file of the git diff panel, or every folder of git status at every depth, when any is open, and unfolds them all when none is; files and folders a later refresh brings follow suit. It is `toggle_folds` under `[git_diff.keybindings]` and `[git_status.keybindings]`. A file folded by hand in the git diff panel now stays folded across refreshes instead of passing its fold to whichever file took its place in the list.
