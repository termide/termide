- **One-line installer for Windows.** `irm https://raw.githubusercontent.com/termide/termide/main/install.ps1 | iex` downloads the latest release, installs to `%LOCALAPPDATA%\Programs\termide` and adds it to PATH — no admin rights needed. On ARM64 Windows 11 the x64 build runs under emulation. Release archives now include `.sha256` checksum files that both installers verify when present.
