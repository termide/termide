- **One-line installer for Windows.** `irm https://raw.githubusercontent.com/termide/termide/main/install.ps1 | iex` downloads the latest release, installs to `%LOCALAPPDATA%\Programs\termide` and adds it to PATH — no admin rights needed. On ARM64 Windows 11 the x64 build runs under emulation. It verifies the download against the release's `.sha256` file and installs nothing when that file is missing or does not match.
