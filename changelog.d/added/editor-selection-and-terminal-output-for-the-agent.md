- **Hand the agent your editor selection or terminal output.** `@selection` and `@term` lead the agent's `@` list: the selection of the editor you last used, and the terminal's selection or else its last 200 lines. Each goes into the prompt as a `[#2 selection src/main.rs:10-24]` placeholder holding the text as it was, spliced in with a line saying where it is from when you send. The editor's `[≡]` menu (while text is selected) and the terminal's offer **Send to agent**, which puts it in the last agent panel used, or a new one, and focuses it; `send_to_agent` can be bound to a key. See [Coding Agent](doc/en/agent.md).
