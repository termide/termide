- **Terminals know the shell's commands.** bash, zsh and fish in a terminal panel mark each prompt and command (`OSC 133`), still reading your own startup files. `Ctrl+Shift+Up` / `Ctrl+Shift+Down` jump from prompt to prompt, a failed command is marked on the panel's left border, the panel menu's **Copy command output** copies the last command's output, and **Send to agent** and `@term` hand over the last command with its output and exit code rather than the last lines of the screen. `shell_integration = false` under `[terminal]` turns it off. See [Terminal](doc/en/terminal.md#shell-integration).
