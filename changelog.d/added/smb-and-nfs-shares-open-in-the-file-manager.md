- **SMB and NFS shares open in the file manager.** `smb://[user@]host/share/path` opens a Windows, Samba or NAS share over SMB 2 or 3, and `smb://host/` lists the server's shares; a refused login asks for the password and can keep it in the vault, and `DOMAIN;user` gives a domain. `nfs://host/export/path` opens an NFSv3 export, and `nfs://host/` lists the exports. Both are built in, with no system library or mount: files open, copy and move between panels, and a file or a whole directory uploads and downloads with progress, pause and cancel. An NFS export that takes only privileged ports or needs Kerberos is refused with a message saying what to change on the server or to mount it with the system. See [Remote filesystems](doc/en/vfs.md#smb-and-nfs).
