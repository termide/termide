- **See what the agents spent across sessions and projects.** The session info (`F3`, `/usage`) becomes the usage window: beside **This session**, **Project** and **All projects** add up every session over today, 7 days, 30 days or all time — tokens, cache hits, by source, model, agent and project, the ten sessions that spent the most (a project's open from the list) and every day of the period with a bar. **AI → Usage…** opens it without an agent panel. The logs are counted once and kept in a cache, so later only the changed ones are read again. Token counts of a billion and more show as `B`. See [Coding Agent](doc/en/agent.md#usage-across-sessions).
