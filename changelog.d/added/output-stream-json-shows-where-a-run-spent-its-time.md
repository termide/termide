- **`--output stream-json` shows where a run spent its time.** Every line carries `elapsed_ms`, the time since the run began; a `tool_result` carries the first 2000 characters of the tool's `output`; the final `result` adds `usage_total`, the whole run's tokens, beside the last answer's `usage`. The reasoning comes as `thinking` lines while the model writes it, a call's arguments past 4000 characters as `tool_input` lines, a call cut for looping as a `loop` line and a reply that hit the output limit with nothing in it as a `cut_off` line, so a run killed by a timeout still shows what its last call was doing. See [Headless mode](doc/en/agent.md).
