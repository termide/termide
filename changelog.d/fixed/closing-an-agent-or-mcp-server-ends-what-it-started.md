- **Closing an external agent or an MCP server ends what it started.** Closing an ACP agent's panel killed its process at once, without the moment to exit that closing its input was meant to give, and left whatever it had started running; a stdio MCP server started through a launcher such as `npx` left the real server behind. Both now get their input closed and a second to exit, then their whole process group is ended, without holding up the panel.
