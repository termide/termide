- **Saving checks the file on disk first.** A save relied on the file watcher alone, which reports a change only after its 300 ms debounce, drops what it cannot keep up with, and took only a newer modification time for a change; so a save right after a formatter, `git checkout` or another program wrote the file overwrote that write unseen. A save now looks at the file itself, and any other modification time, older or newer, or another size refuses it as a change on disk. When the watcher itself reports an error, or that the system dropped changes it could not keep up with, the panels look at their files again.
