- **Python plugins written with the example library get their events in order.** `examples/plugins/sdk/termide_plugin.py` handled events on a pool of four threads, so an `editor/changed` could be handled before the one sent ahead of it; events now run one at a time, in the order termide sent them, while requests still run side by side. A request the plugin has no handler for is answered with JSON-RPC's "method not found" instead of `null`.
