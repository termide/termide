- **Copies and moves to a server ask before overwriting.** Copying or moving several entries to an SFTP or FTP location asked about a name taken on the server only for the first entry; the rest overwrote what was there, or asked about a local file that happened to share the path. Each entry is now looked up on the server, and an upload resumed after the conflict dialog uploads instead of failing. Several entries copied or moved within one server all go, not only the first.
