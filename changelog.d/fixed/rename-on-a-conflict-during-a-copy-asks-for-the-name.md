- **Rename on a conflict during a copy asks for the name.** When a file appeared at the destination after a copy or move had started, Rename in the conflict dialog skipped the file. It now asks for the new name with the same pattern prompt as a conflict found before the copy, and the file lands under that name; a name that is taken too is asked about first, and Esc on the prompt goes back to the conflict dialog. Overwrite on a picked name that is taken replaces the file under that name, before a copy too, where it replaced the file first asked about.
