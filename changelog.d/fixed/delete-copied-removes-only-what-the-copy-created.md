- **"Delete copied" removes only what the cancelled copy created.** After cancelling a batch, it targeted each source's name in the destination: it missed an item copied under a new name and could delete a file that had been overwritten or a directory the copy was merged into, data that was there before. It now removes exactly the entries the copy created, under the names they were written as, and a cancelled move no longer offers to delete anything, since its items have no originals left.
