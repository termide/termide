- **A debug command runs where its `cwd` says.** Commands with a `debugger` always ran in the project root, so one from a `commands.toml` linked in from another repository looked for its program in the wrong folder, and `cwd = "panel"` did nothing. They now run where a shell command with `cwd = "project"` runs, or in the focused panel's directory with `cwd = "panel"`. Mistakes in `commands.toml` — an unknown `mode`, parameter `type` or `console`, a misspelt key — are now written to the log instead of passing unnoticed, and the field table lists `debugger_args`.
