- **An accented letter is one character in input fields.** A name spelled with a combining accent, as macOS file names are, showed a blank cell after the letter in rename, find, path and other single-line fields; the cursor and clicks landed one cell off, and Backspace removed only the accent. The multi-line inputs — the agent prompt, the commit message and plugin dialog fields — took two steps over such a letter, deleted only its accent and moved up and down by character count rather than by column. Fields now draw, wrap, move, select and delete by whole letter.
