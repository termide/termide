- **An SFTP transfer leaves the file it replaces intact until it is complete.** A download or an upload emptied the file it replaced first and left it half-written when cancelled or cut off; each now writes a hidden sibling that takes the old file's place at the end, and an upload keeps the replaced file's permission bits (a symlink on the server is still written through). A directory download refuses an entry name a server gives with a path in it, and one nested too deep fails instead of being skipped, so a move no longer deletes from the server what it did not bring down.
