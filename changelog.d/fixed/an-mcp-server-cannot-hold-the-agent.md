- **An MCP server cannot hold the agent.** A stdio server that stopped reading its input could block a request, and every later one, past any timeout; a remote server streaming its answer could keep a cancelled tool call waiting; a server whose tool list paged in a circle was read forever. Requests now always end at a cancel or their timeout, and the server is then sent `notifications/cancelled`; the tool list stops at a cursor it has seen and after 100 pages.
