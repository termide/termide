- **Status bars, the find bar and messages speak the interface language.** The status bars of the editor, the hex viewer, the Markdown, HTML, diagram, CSV and image viewers, the find and replace bar, the command palette, the go-to-line and rename prompts, the cancelled-copy and bookmark dialogs, the background-operations indicator ("Copying 40% (+2 queued)"), the git push, pull and fetch notices, and the messages about stashes, staging, commits, deletes, saves and reloads, uploads and remote copies, failed operations, SSH and git start-up, fetched pages and images, code actions, plugins and failed opens were English in every language; they now follow the interface language. An NFS address now says, like SMB, that its connections are not supported yet. One pasted line or one copied character also reads as singular in German, Spanish, French and Portuguese ("1 Zeile", "1 carácter" rather than "1 Zeilen", "1 caracteres"), and a few labels left in English in Indonesian, German, Spanish, French, Portuguese and Russian are translated.
