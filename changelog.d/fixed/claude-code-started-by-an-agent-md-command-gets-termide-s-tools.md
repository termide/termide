- **Claude Code started by an `AGENT.md` `command` gets termide's tools.** An agent defined with `command: npx -y @agentclientprotocol/claude-agent-acp`, in a panel or as a subagent, was served an MCP server with no tools in place of its own, so it could not read a file or run a command; it is now served the same tools as a `claude_code` connection's agent, and Codex and Gemini CLI agents defined that way get the companion tools and MCP servers' tools a connection gives them.
