- **The installer fits the build to your system and checks every package.** `install.sh` installed the gnu build on any system with a glibc loader, though it needs glibc 2.34, so on RHEL 8, Debian 11 or Ubuntu 20.04 termide would not start; it now takes the static musl build there. The `.rpm` now requires glibc 2.34 instead of installing where it cannot run. The `.deb` and `.rpm` the installer downloads are checked against the `.sha256` files the release now publishes beside them, and the `.deb` goes in through apt, which brings its dependencies. The installer uses `sudo` only where the directory needs it (not as root, nor under Termux, where it installs into `$PREFIX/bin`), takes `TERMIDE_VERSION` and `TERMIDE_INSTALL_DIR` as `install.ps1` does, and the installation guide now describes it. The download links in the docs name the release they belong to.
