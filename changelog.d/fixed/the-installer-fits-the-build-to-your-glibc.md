- **The installer fits the build to your system and checks every download.** `install.sh` installed the gnu build on any system with a glibc loader, though it needs glibc 2.34, so on RHEL 8, Debian 11 or Ubuntu 20.04 termide would not start; it now takes the static musl build there. The `.rpm` now requires glibc 2.34 instead of installing where it cannot run. Every release archive and package now comes with a `.sha256` file beside it, and the installer checks each download against it and installs nothing when the file is missing or does not match; the `.deb` goes in through apt, which brings its dependencies. The installer uses `sudo` only where the directory needs it (not as root, nor under Termux, where it installs into `$PREFIX/bin`), takes `TERMIDE_VERSION` and `TERMIDE_INSTALL_DIR` as `install.ps1` does, and the installation guide now describes it. The version it names is the one it installs with Cargo and Nix too, which built the latest commit on `main`; Homebrew, which cannot be pinned, is said to install the tap's current version. The download links in the docs name the release they belong to.
