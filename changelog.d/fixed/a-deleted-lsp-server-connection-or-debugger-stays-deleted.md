- **A deleted LSP server, connection or debugger stays deleted.** Settings saved only what differed from the layer below, so deleting a built-in LSP server came back on the next start, renaming one kept both, and a project could not remove a connection, debugger or LSP server of the global settings. Such a deletion is now written as `<name> = false` under its table, which removes the entry; the same line works by hand.
