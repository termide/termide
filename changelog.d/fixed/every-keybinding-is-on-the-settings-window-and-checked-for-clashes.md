- **Every keybinding is on the settings window and checked for clashes.** `open_agent` (`Alt+A`) and the editor's `code_action` (`Alt+Enter`) had no row under **Keybindings**, so only `config.toml` could rebind them, and an editor key bound to the viewer's `Ctrl+E` or `Ctrl+L`, which the editor matches first, never fired and drew no warning. Both now have rows, and `[viewer.keybindings]` is checked with the rest.
