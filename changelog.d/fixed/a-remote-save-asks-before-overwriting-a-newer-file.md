- **Saving a file opened from a server asks before overwriting a newer one, and a failed upload stays unsaved.** The upload replaced the file on the server whatever happened to it there since it was opened. Now, when the file changed on the server since it was opened or last saved, the editor asks whether to overwrite it; declining keeps the edits unsaved. The save also cleared the modified mark before the upload ran, so when the upload failed or was cancelled the editor looked saved and closed without asking, though the edits were only in the local copy; the buffer is now marked unsaved again.
