- **Language server edits and jumps land where the server means.** Rename and code-action edits to files that are not open counted columns in code points instead of UTF-16 units, so text after an emoji was cut in the wrong place; paths with spaces or non-ASCII names in a server's URIs were not decoded, so those files were skipped or not found by go to definition, references and diagnostics; an edit that failed halfway left earlier files written and later ones not; and an edit sent as a list of document changes was ignored. Files are now all read and edited before any is written, each written atomically; document changes are applied, and an edit that asks to create, rename or delete files is refused whole with a message instead of half-applied. Go to definition, references and the diagnostics panel also convert the server's column, so the cursor lands on the right character after an emoji or accent.
