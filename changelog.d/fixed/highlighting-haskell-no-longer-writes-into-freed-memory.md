- **Highlighting Haskell no longer writes into freed memory.** The Haskell grammar's scanner keeps writing to its lookahead buffer through a pointer from before the buffer grew, once its C code is compiled with strict aliasing, as optimised builds are. Reparsing a pragma (`{-# … #-}`) as you edit could corrupt memory or abort termide, which glibc does on Linux. The grammars' C code is now built with `-fno-strict-aliasing`. The AUR source package keeps it under makepkg's own `CFLAGS` and builds without makepkg's LTO, which broke the link (undefined `tree_sitter_*` symbols).
