- **A message sent just as an external agent finishes starting is no longer lost.** With Claude Code, Codex or Gemini CLI over ACP, a message that arrived as the agent's session opened could end its turn at once without being sent: the panel showed the run over and the message went nowhere until you sent another. Claiming the turn and queueing its message now happen together, so the session's opening finds the message in place, and the same holds for trying a failed turn again.
