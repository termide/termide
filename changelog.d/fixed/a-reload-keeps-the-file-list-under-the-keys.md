- **A reload keeps the file list under the keys.** Refreshing a folder — with Ctrl+R, after a copy or move, after toggling hidden files, or when the watcher had to rescan a busy disk — emptied the list and put the cursor on its first row until the folder was read again, so keys pressed meanwhile were lost. The list now stays as it was until the new one is in, and the cursor stays where it is, or where you have moved it since.
