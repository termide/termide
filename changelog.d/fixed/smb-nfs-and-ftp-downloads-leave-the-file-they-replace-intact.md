- **SMB, NFS and FTP downloads leave the file they replace intact until they are complete.** A download emptied the local file it replaced first, wrote through a symlink found there, and left the file half-written when cancelled or cut off; it now writes a hidden sibling that takes the file's place at the end, keeping its permission bits. A directory download from SMB or NFS refuses an entry name with a path in it, and one nested too deep fails instead of being skipped, so a move no longer deletes from the server what it did not bring down.
