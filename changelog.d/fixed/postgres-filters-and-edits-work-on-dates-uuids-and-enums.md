- **PostgreSQL filters and edits work on dates, UUIDs and enums.** In the database panel, a filter on a PostgreSQL column of a type other than text or number — `timestamp`, `date`, `uuid`, `inet`, `json`, an enum — failed with `operator does not exist`, a “contains” filter on one failed the same way, and editing such a cell, or setting it to NULL, was refused with `column is of type … but expression is of type text`. The value is now converted to the column's type, and “contains”, “starts with” and “ends with” match the column's text.
