- **A connection switch the agent panel refuses no longer leaves it half switched.** With a task still running in the background, switching the connection — say, from a CLI agent on a subscription to local inference after a limit — was refused with a notice, yet the status bar already showed the new connection and its model while the old agent kept answering and soon put its own model back on the Model chip. The switch, and an agent switch onto or off a CLI agent, now changes nothing when it is refused; a settings edit to the connection waits for the background tasks as it waits for a run.
