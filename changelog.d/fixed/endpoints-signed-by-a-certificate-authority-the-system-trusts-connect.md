- **Endpoints signed by a certificate authority the system trusts connect.** Model connections, MCP servers over HTTP and `fetch` trusted only the certificates bundled with termide, so behind a corporate TLS proxy, or with an endpoint on an internal certificate authority, every request failed with `UnknownIssuer` and only a rebuild helped. They now trust the system's store as well, and `SSL_CERT_FILE` or `SSL_CERT_DIR` can name the authority instead; the bundled set still applies where the system store is missing. Verification still cannot be switched off.
