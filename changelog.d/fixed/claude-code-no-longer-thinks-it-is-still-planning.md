- **Claude Code no longer thinks it is still in plan mode while it carries a plan out.** A Claude Code session started in plan mode kept the plan instructions in its system prompt for good. Only one note said the mode was off, and Claude Code's compaction could drop it. The instructions now come as a note ahead of the turn, never in the system prompt, and the current mode is told again after a compaction and when a session is resumed. The plan card also offers "from a clean context" on Claude Code, Codex and Gemini CLI: it starts a new session of the agent with a recap of the decisions and the plan.
