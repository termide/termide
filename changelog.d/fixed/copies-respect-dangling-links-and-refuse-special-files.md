- **Copies ask about a dangling link and refuse pipes and devices.** A broken symbolic link at the destination was replaced without the usual conflict question, and a broken link among the sources was rejected as an unsupported type; it is now asked about, and copied as a link. Copying a pipe, a socket or a device no longer hangs or runs forever (a FIFO waited for a writer, `/dev/zero` never ended): the copy stops with an error naming it. An upload to a server refuses a selected one the same way instead of opening it.
