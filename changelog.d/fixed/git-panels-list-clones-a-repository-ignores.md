- **Git panels list the repositories cloned inside a repository.** A clone the project's repository ignores or does not track — `domovik/` under a root whose `.gitignore` holds `/domovik/` — was missing from the repository list, since only submodules were sought inside a repository. Such clones are now listed at any depth, and the agent's `recall` searches their history. They come from one `git ls-files`, which reports an ignored or untracked directory without entering it, so a large `node_modules/` or `target/` costs nothing; a clone inside an ignored directory is not sought.
