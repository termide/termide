- **Unstaging or reverting a renamed file takes the whole rename.** After `git mv old new`, unstaging `new` in the git status panel, the git diff panel or a file's properties left `old` staged as deleted beside an untracked `new`, and reverting it failed. Unstaging now takes the rename's source out of the index too, and reverting undoes the rename: `old` comes back as committed and `new` is removed.
