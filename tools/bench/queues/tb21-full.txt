# The full Terminal-Bench 2.1, one attempt per task and one trial at a time,
# for the harness comparison on a hosted and two local models
# (tools/bench/queue.sh tools/bench/queues/tb21-full.txt). The agent's time
# is the dataset's own (×1): what a task scores compares only at that.
#
# The setup limit is ×8 for every harness alike. It costs no agent time —
# Harbor times the agent from its own start, after the install — but when it
# expires the task gets no verdict at all and is lost from the run
# (install-windows-3.11 took the whole 24 minutes of ×4 installing qemu).
# Nothing in a comparison should hinge on how fast a mirror answers, so the
# install gets as much room as it needs; only the wall clock pays.
#
# Claude first: it shows the queue working within a day or two.
# The first job of the pair was cut off at 54 of 89 on 2026-11-19 and its
# config cannot be resumed (harbor masks the token it was passed, and the
# job's lock covers that config), so its 35 remaining tasks run as -r and
# the report merges the two: tb21-claude-code-sonnet55+tb21-claude-code-sonnet55-r.
tb21-claude-code-sonnet55-r  tb21-claude-rest  AGENT=claude-code MODEL=claude-sonnet-5-5 --agent-setup-timeout-multiplier 4
tb21-termide-acp-sonnet55     all  AGENT=termide-claude-code MODEL=claude-sonnet-5-5 --agent-setup-timeout-multiplier 8
# Then each local model with the three harnesses in turn, so OMLX loads it
# once.
