# Политика подписи кода

Бинарные файлы Termide для Windows подписываются, чтобы не вызывать
предупреждений безопасности (SmartScreen, Smart App Control).

Бесплатная подпись кода предоставлена [SignPath.io](https://about.signpath.io/),
сертификат от [SignPath Foundation](https://signpath.org/).

## Роли

- **Коммитеры и ревьюеры:**
  [Участники](https://github.com/orgs/termide/people)
- **Утверждающие (запросы на подпись):**
  [Владельцы](https://github.com/orgs/termide/people?query=role%3Aowner)

## Политика приватности

Termide не передаёт информацию другим сетевым системам, кроме случаев, когда
этого явно запросил пользователь или администратор.

Агент-программист подключается только к эндпоинтам моделей (локальным или
облачным), которые настроил пользователь; по умолчанию никакие данные никуда не
отправляются. Termide не ведёт телеметрию, не проверяет обновления и не требует
учётной записи.
