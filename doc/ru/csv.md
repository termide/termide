# Просмотр CSV в виде таблицы

Termide показывает текстовые файлы с разделителями (`.csv`, `.tsv`) как
таблицу: заголовки столбцов, сетка ячеек и курсор ячейки — вместо сырого
текста. Таблица только для чтения; править файл — как текст в редакторе.

## Открытие

- **`F3`** на файле `.csv` / `.tsv` в файловом менеджере — открыть таблицу.
- **`Enter`** или **`F4`** — открыть текст в редакторе (как любой текстовый
  файл).
- Open… (`Ctrl+G`), закладка или переход по ссылке на такой файл тоже
  открывают таблицу.

Файл не загружается в память. Фоновый проход находит, где начинаются его
строки, а с диска читаются только строки вокруг экрана, поэтому файл любого
размера открывается сразу. Первые строки видны, как только найдены. Пока
проход идёт, в углу показано `Загрузка…`, а число строк в строке состояния
кончается на `…`.

## Таблица ↔ Исходник

Таблица и редактор исходника — два вида одного файла. Переключение на месте —
панель заменяется, а не открывается рядом:

- **`Ctrl+E`** (настраивается в `[viewer.keybindings] toggle_view`).
- Кликабельный чип **`Edit`** в строке состояния.

Пока в исходнике есть несохранённые изменения, вернуться к таблице нельзя —
сначала сохраните.

## Устройство файла

Просмотрщик угадывает две вещи; они показаны в строке состояния, и там же их
можно переключить кликом — или из меню панели `[≡]`:

- **Разделитель** — `,`, `;`, `Tab` или `|`: тот, что чаще всего делит первые
  записи на одинаковое число полей. Для `.tsv` всегда `Tab`. Переключение
  перебирает все четыре и перечитывает файл.
- **Заголовок** — называет ли первая запись столбцы. Она считается заголовком,
  если ни одно её поле не пустое и не число. Без заголовка столбцы называются
  `A`, `B`, `C`, … как в электронной таблице.

Поля в кавычках могут содержать разделитель и переносы строк; перенос внутри
ячейки показан как `↵`. Строки разной длины показываются как есть, а файл не в
UTF-8 читается с заменой неверных байтов.

## Клавиши

| Клавиша | Действие |
|---------|----------|
| `↑` `↓` `←` `→` | Двигать курсор ячейки |
| `PageUp` / `PageDown` | На экран вверх / вниз |
| `Home` / `End` | Первая ячейка / последняя строка |
| `s` | Сортировка по столбцу курсора: по возрастанию, по убыванию, как в файле |
| `y`, `Ctrl+C` | Копировать ячейку под курсором |
| `Ctrl+R` | Перечитать файл |
| `Ctrl+E` | Перейти к исходнику в редакторе |

Клик по ячейке ставит туда курсор; клик по заголовку столбца сортирует по нему,
как `s`. Числа сортируются по значению и раньше текста; пустые ячейки — в
конце. Сортировка ещё раз прочитывает столбец в фоне: пока она не готова,
таблица остаётся в прежнем порядке, а в углу показано `Сортировка…`. Меню
панели `[≡]` ещё копирует всю строку через табуляцию — готово для вставки в
электронную таблицу.
