# Общее устройство окна приложения

**Приложение занимает всё доступное место и имеет вертикальное разделение на элементы:**
- Строка меню
- Область панелей инструментов
- Статусная строка

Также приложение использует всплывающие окна:
- Помощь
- Настройки
- Подтверждение закрытия приложения

## Модальные окна

Приложение использует интерактивные модальные окна для различных операций:
- **Встроенные строки поиска / замены** (`Ctrl+F` / `Ctrl+H`) - Докнутые поиск и замена прямо в редакторе, файловом менеджере и терминале: живой предпросмотр, счётчик совпадений, тумблеры `[Aa]` / `[.*]` и кнопки навигации
- **Модалы ввода** - Различные запросы для файловых операций (создание, переименование и т.д.)
- **Диалоги подтверждения** - Подтверждение удаления, несохранённых изменений и т.д.

**Возможности модалов:**
- Кнопка `[X]` для закрытия в заголовке модала (нажимается мышью)
- Навигация с клавиатуры через Tab/Shift+Tab (между полями / кнопками модала)
- Поддержка мыши для всех кнопок
- Клавиша Escape для закрытия модала; клик мимо списка выбора, чек-листа, поля ввода, подтверждения или информационного окна закрывает его так же
- Живой предпросмотр для операций поиска/замены
- Сохранение состояния (последний введённый текст сохраняется)

### Модал настроек (Settings)

Открывается клавишей `Alt+P` или через меню **Options → Edit preferences**. В отличие от прежнего горизонтально-табового варианта, теперь используется **sidebar-layout**:

**Три зоны:**
- **Левый sidebar** (ширина 18 символов) — список секций с навигацией Up/Down
- **Область контента** — поля выбранной секции, сгруппированные подзаголовками `── Группа ──` и разделённые пустыми строками
- **Кнопки снизу** — `Apply & Save`, `Reset`, `Cancel`

**Секции в sidebar:**
- General, Editor, File Manager, Terminal, LSP, Logging, VFS — обычные листья
- **Keybindings** — раскрываемая группа (▶/▼) с 7 подсекциями (Global, Editor, FileManager, GitStatus, GitDiff, GitLog, Terminal)

**Навигация:**

| Комбинация | Действие |
|-----------|----------|
| `Up` / `Down` | Перемещение внутри текущей зоны (секции / поля / кнопки) |
| `Tab` / `Shift+Tab` | Переключение между зонами (Sidebar ↔ Content ↔ Buttons) |
| `Left` / `Right` | **Не** меняют зону: используются для изменения значений (cycle enum, toggle bool) и для свёртки группы Keybindings в sidebar |
| `Enter` / `Space` | Активировать: в sidebar — войти в секцию, в content — переключить bool/enum или начать редактирование текста/числа, на header группы — toggle expand |
| `Escape` | Закрыть модал (Cancel) |
| Колесо мыши | Прокрутка sidebar / content |

**Поля и индикаторы:**
- **Bool** — `[✓]` (включено) или `[ ]` (выключено), переключаются `Enter`/`Space` или `Left`/`Right`
- **Enum** — `< значение >`, циклятся `Left`/`Right`
- **Number** / **OptionalText** — `Enter` входит в режим inline-редактирования
- **LSP → Servers** — список серверов помечен буллетом `•`; есть строка `+ Add Server`

**Keybindings — редактирование бинда:**  
Навигация по списку — `Up/Down`. В каждой строке перечислены все клавиши действия — `Alt+W, Alt+X, F10` — и курсор стоит на одной из них:

| Клавиша | Действие |
|----------|--------|
| `Left` / `Right` | Переместить курсор по клавишам строки; за последней клавишей он встаёт на кнопку `[+]` |
| `Enter` | Захватить нажатие для слота под курсором — заменить эту клавишу, а на `[+]` — добавить новую альтернативу |
| `Delete` | Убрать клавишу под курсором |
| `Shift+Delete` / `Backspace` | Очистить все клавиши действия |
| `Escape` | Выйти из списка, либо отменить начатый захват |

На фокусной строке в конце нарисована кнопка `[+]`: клик по ней или `Enter` на ней начинают захват, и клавиша дописывается в конец. Клик по клавише выбирает её, так что следующий `Enter` или `Delete` действует на то, по чему кликнули; двойной клик по клавише начинает захват. Комбинацию, которая у этого действия уже есть, панель не принимает и показывает почему; комбинацию, занятую другим действием, записывает с предупреждением, где именно она занята. Во время захвата строка продолжает показывать свои клавиши, а та, что будет заменена, помечена предупреждающим цветом.

Подсветка активной секции в sidebar убирается при потере фокуса — текущая секция видна по заголовку в области контента, поэтому двойная подсветка не вводит в заблуждение.

## Строка меню

Строка меню располагается вверху окна и включает: пункты меню расположенные слева, индикаторы системных ресурсов (скорость сети, CPU, RAM и — если есть батарея — её заряд) и часы в формате ЧЧ:ММ расположенные справа.
Активация и деактивация меню, а также каждого пункта может производиться кликом мыши либо [клавиатурной комбинацией](#клавиатурная-навигация-и-управление-по-меню-и-панелям).

**Пункты меню:**
- `Закладки` — закладки (директории, файлы, SSH, SFTP, веб-ссылки). Открытие маршрутизируется по типу: директории и удалённые пути — в файловом менеджере, файлы HTML/Markdown/Mermaid/изображения и `http(s)`-ссылки — во встроенном просмотрщике (см. [просмотр HTML](html.md); учитывает `[viewer] open_links`), прочие текстовые файлы — в редакторе, SSH — в терминале, базы данных — в DB-просмотрщике. Клик по заголовку группы разворачивает и сворачивает её подменю, как в «Командах».
- `Команды` — пользовательские команды, сначала проектные (жирным), с группами подменю; `Добавить команду...` вверху создаёт новую. Клик по заголовку группы разворачивает подменю; повторный клик на том же заголовке — сворачивает (toggle). См. [Пользовательские команды](actions.md).
- `Проекты` — управление проектами:
  - Новый проект — начать проект в другой директории
  - Переключить проект — открыть модальное окно переключения (`Alt+\`). В нём проекты перечислены так же, как в меню ниже, по одной строке — отметка, когда в последний раз работали с неоткрытым проектом (блёклым цветом), путь и 🔔, — а строка под курсором инвертирована. Ввод фильтрует список по пути. Курсор сразу стоит на проекте, из которого вы ушли последним: `Alt+\`, затем `Enter` возвращает в него. `Delete`/`F8` работают так же, как в меню
  - Изменить корневой путь — переместить текущий проект в другую директорию

    Директория в обоих случаях выбирается в дереве: `→`/`←` раскрывают и сворачивают ветку, `Enter` входит в директорию, `Backspace` поднимается к родительской, `.` показывает или скрывает скрытые директории, `Ctrl+Enter` подтверждает выбор из любого места
  - Открыть проекты прошлого запуска (N) — появляется, если в прошлом запуске было открыто больше одного проекта, и пропадает, когда вы им воспользуетесь или сами откроете другой проект. Открывает эти проекты в фоне, оставляя вас в текущем; раскладка каждого загружается при первом переключении на него, в терминалах запускаются новые оболочки. Список сохраняется при каждом изменении набора открытых проектов, поэтому переживает аварийное завершение; запуск, в котором так и не открыли второй проект, его не трогает. Если запущено несколько экземпляров, побеждает тот, что последним изменил свой набор
  - Под разделителем — все проекты, с которыми вы работали. Сначала открытые в этом экземпляре, по пути, затем, под ещё одним разделителем, остальные, недавно использованные выше; длинный список прокручивается. Строка выглядит так же, как в окне переключения: отметка, время последней работы с неоткрытым проектом (блёклым цветом), путь — если он не помещается, обрезается его начало — и 🔔. ● отмечает текущий проект, ○ — открытый в фоне, 🔔 — проект, панель которого ждёт вас (вопрос или законченная работа агента, звонок в терминале); пока такой есть, заголовок `Проекты` выделен фоном цвета предупреждения. `Enter` или щелчок переключает. `Delete`/`F8` закрывает проект, открытый в фоне, и останавливает запущенные в нём программы, а у неоткрытого удаляет сохранённую раскладку, и он пропадает из списка (файлы проекта не трогаются); оба действия спрашивают подтверждение, текущий проект не трогается
  - При переключении на другой проект тот, в котором вы были, остаётся открытым в фоне: программы в его терминалах продолжают работать, агенты — тоже, несохранённые правки остаются как были. Проект открыт, пока вы его не закроете или пока TermIDE не завершится. «Новый проект» в уже открытой директории переключает на неё. При выходе TermIDE называет фоновые проекты, в которых ещё что-то работает. Между открытыми проектами с клавиатуры переключают `prev_project`, `next_project` и `goto_project_1`…`goto_project_9`; по умолчанию они не назначены, см. [Действия без привязки](keybindings.md#действия-без-привязки)
- `AI` — агенты, сессии, скиллы и промпты агента, а также переключатель окна браузера агентов; см. [Меню AI](agent.md#меню-ai)
- `Окна` — создание панелей:
  - Открыть… — открыть файл, каталог или URL через строку ввода с подсказками (`Ctrl+G`)
  - Терминал — терминал (имеет подменю выбора оболочки: показывает все доступные в системе оболочки, текущая оболочка по умолчанию отмечена ●)
  - Файлы — файловый менеджер
  - Редактор — текстовый редактор
  - Git статус — панель статуса git
  - Git история — история коммитов
  - Журнал — журнал приложения
  - Диагностика — диагностика LSP
  - [Операции](operations.md) — фоновые операции
  - Структура — структурная навигация по коду
  - [Агент](agent.md) — панель агента
- `Опции` — настройки:
  - Темы — выбор темы с предпросмотром
  - Язык — язык интерфейса с предпросмотром
  - Настройки — открыть окно настроек
  - Помощь — панель помощи
  - Отсоединить экземпляр — оставить экземпляр работать в фоне (показывается, только когда отсоединение возможно; см. [Отсоединяемые экземпляры](detached-instances.md))
  - Выход — закрыть приложение

**Индикаторы системных ресурсов** (кликабельные индикаторы открывают модальное окно с подробностями):

| Индикатор | Описание | Клик открывает |
|-----------|----------|----------------|
| `↓…/↑…` | Скорость сети (↓ загрузка, ↑ отдача) | Топ-10 процессов по сетевой активности |
| `CPU XX%` | Загрузка процессора | Топ-10 процессов по CPU |
| `RAM X/YГб` | Использование памяти | Топ-10 процессов по RAM |
| `⚡NN%` / `🔋NN%` | Заряд батареи (⚡ — от сети / заряжается / заряжена, 🔋 — от батареи). Скрыт на системах без батареи. | — (только информация) |
| `УСТРОЙСТВО занято/всегоГб` (в статусной строке) | Использование диска | Топ-10 процессов по диску + разделы ФС |

Повторный клик по тому же индикатору закрывает открытое им окно (toggle), то же поведение и у индикатора диска в статусной строке.

Цветовая кодировка (CPU / RAM): зелёный < 50%, жёлтый 50–75%, красный > 75%. Батарея использует ту же шкалу наоборот (зелёный при зарядке или выше 50%, красный ниже 25%). Показания батареи кэшируются на 5 секунд, чтобы покадровая отрисовка не обращалась к `/sys`.

**Модал сетевой активности** показывает:
- **Application** — имя процесса
- **Ports** — слушающие TCP-порты (например, `80, 443`)
- **Conn** — количество активных (ESTABLISHED) соединений

Процессы отсортированы по убыванию числа соединений.

## Область панелей инструментов

Область заполняет вертикальное пространство между строкой меню и статусной строкой от левого до правого края окна.
Раскладка адаптируется к ширине терминала, показывая больше групп панелей на широких экранах. Панели (терминал, редактор, git) могут быть открыты и будут размещены рядом.

Новая панель всегда открывается **после текущей активной** в аккордеоне группы (не в конце списка). При закрытии панели фокус переходит на предыдущую.

**Возможные варианты открываемых панелей:**
- [файловый менеджер](file-manager.md) — `Alt+F`
- [терминал](terminal.md) — `Alt+T`
- [текстовый редактор](editor.md) — `Alt+E`
- статус git — `Alt+G`
- структура (outline) — `Alt+O`
- диагностика — `Alt+I`
- git лог — `Alt+C`
- git diff
- [агент-программист](agent.md) — `Alt+A`
- [операции](operations.md)
- просмотр изображений
- помощь — `Alt+H`
- журнал — `Alt+L`

Панель **git статус** сверху показывает два селектора: репозиторий и ветку.
В списке веток — локальные ветки и удалённые без локального двойника; `●`
отмечает ветку, выгруженную в основную копию репозитория, `⧉` — выгруженную в
связанный worktree (каталоги worktree не попадают в список репозиториев
отдельными записями). Выбор ветки никогда её не выгружает — он лишь меняет то,
что показывает панель:

- ветка, выгруженная в основную копию или в worktree, показывает изменения
  этой рабочей копии, и индексация, коммит, diff, push и pull выполняются в ней;
- ветка, не выгруженная никуда, показывает, на сколько коммитов она впереди и
  позади ветки основной копии, и кнопку `[Переключиться]`, которая выгружает её в
  основную копию. Если git отказывает (например, мешают незакоммиченные
  изменения), его сообщение показывается как ошибка.

`[Лог]` открывает git лог на том же репозитории и ветке. Селектор веток в логе
помечает ветки так же и лишь выбирает, чью историю показать; после checkout лог,
следящий за HEAD, переходит на новую ветку.

Панель **git лог** рисует граф коммитов псевдографикой (`● │ ├ ╮ ╯`),
раскладывая его по родителям каждого коммита; каждая дорожка раскрашена своим
цветом, чтобы ветку можно было вести глазом по цвету. Чтобы вернуться к нативному
ASCII-выводу git `--graph`, задайте в `config.toml`:

```toml
[git_log]
unicode_graph = false
```

Лог читает историю по мере прокрутки: первые коммиты видны сразу, а следующие
дочитываются, пока до конца прочитанного остаётся меньше двух экранов; под
последним в это время стоит строка *Загружаю коммиты…*. `End` дочитывает
историю до конца, какой бы длинной она ни была, и держит выделение на последнем
коммите. Полоса прокрутки с самого начала охватывает всю историю. Когда лог
перечитывается — после коммита, checkout, rebase, — выделенный коммит остаётся
выделенным и на том же месте экрана.

Открытие **бинарного файла** (по `Enter` или `F3` в файловом менеджере)
показывает read-only **hex-вьюер** — `смещение │ hex │ ASCII`, ширина строки
подстраивается под панель секциями по 16 байт — вместо передачи системному
просмотрщику. Курсор байта виден сразу в hex- и ASCII-зонах (`Tab` переключает
активную); стрелки/`hjkl` двигают его, `Shift`+движение выделяет, `Ctrl+C`
копирует выделение (как hex из hex-зоны, как текст из ASCII-зоны). `Ctrl+F`
открывает поиск по ASCII-подстроке или — с тумблером `[hex]` — по
последовательности байт вида `ff fe`; совпадения подсвечиваются в обеих зонах.

Открытие бинарного файла по `F4` (редактирование) делает его **редактируемым**:
ввод перезаписывает байт под курсором — два hex-нибла в hex-зоне, символ в
ASCII-зоне — без изменения длины файла. Несохранённые правки помечаются `*` в
заголовке; `Ctrl+S` сохраняет после подтверждения, предварительно делая бэкап
оригинала в `<файл>.bak`.

`Ctrl+L` (или чип `[Hex]`/`[Text]` в статус-баре) переключает hex и текст. Для
настоящего текстового файла это подменяет панель на месте read-only редактором
(а `Ctrl+L` в редакторе возвращает в hex); бинарный файл — который редактор не
может открыть как текст — переключается в lossy-текстовый режим внутри панели.
Клавиша настраивается:

```toml
[viewer.keybindings]
toggle_hex = "Ctrl+L"
```

**Особенности закрываемых панелей:**
- Имеют кнопку `[≡]` в заголовке панели (клик открывает контекстное меню с пунктами Закрыть / Отделить / Объединить / Переместить)
- Могут быть закрыты клавишами Escape, Alt+W, Alt+X или F10
- Ширина колонки регулируется клавишами `Alt+=` / `Alt+-`
- Высота панели внутри колонки регулируется `Alt+Shift+=` / `Alt+Shift+-` (шаг 1 строка), перетаскиванием нижнего бордюра панели мышью или перетаскиванием заголовка панели вверх/вниз внутри колонки
- `Alt+F11` переключает «полноэкранный пресет» для активной панели (одна панель занимает всю колонку, остальные сжимаются до строки заголовка); повторное нажатие восстанавливает прежние высоты
- Некоторые панели подстраивают высоту под содержимое, а не берут долю колонки — так ведёт себя панель операций — и сохраняют её при полноэкранном пресете (фокус на такой панели не сворачивает развёрнутую панель); ручное изменение высоты такой панели даёт ей обычную фиксированную высоту до закрытия
- Могут перетаскиваться за верхний бордюр (см. раздел «Взаимодействие мышью» ниже)

**Контекстное меню действий панели:**

Клик по кнопке `[≡]` в заголовке панели (или нажатие `Alt+K` / `Shift+F10` на активной панели) открывает выпадающее меню:
- **Переместить вверх / Переместить вниз** — переупорядочить внутри текущей группы (если в группе больше одной панели)
- **Переместить влево / Переместить вправо** — в соседнюю группу (если групп больше одной)
- **Отделить / Объединить** — отделить панель из группы в новую (если в группе больше одной панели) или объединить одиночную панель с соседней группой
- **Закрыть** — закрыть панель (с подтверждением при необходимости)

Пункты фильтруются по контексту: например, *Отделить/Объединить* скрывается, если всего одна панель в одной группе; *Переместить вверх/вниз* — для одиночной панели в группе.

**Взаимодействие мышью:**
- Клик по заголовку активирует панель; двойной клик по заголовку
  файлового менеджера открывает выбор каталога.
- **Перетаскивание бегунка скроллбара** (блок `▌` на правом бордюре
  панели или `━` на нижнем, где нарисован горизонтальный скроллбар) —
  прокрутка панели в эту позицию. Захватывается только бегунок:
  дорожка скроллбара и бордюр без скроллбара по-прежнему меняют
  раскладку, как описано ниже. Перетаскивание бегунка неактивной
  панели прокручивает её на месте, не перемещая фокус, — так же, как
  колесо мыши.
- **Перетаскивание нижнего бордюра панели** в колонке — изменение
  высоты этой панели (живая ghost-линия `━` показывает положение
  нового разделителя, ресайз применяется на отпускании).
- **Перетаскивание панели за верхний бордюр (title)** — режим
  resize или reorder:
  - Отпускание в теле исходной панели или в теле верхнего соседа
    → вертикальный resize: разделитель над панелью прыгает к
    курсору (у верхней панели колонки разделителя выше нет —
    жест переходит в режим переноса).
  - Отпускание на строке-заголовке другой панели в той же группе
    → переупорядочивание: вставить перед / после в зависимости
    от направления.
  - Отпускание над телом панели другой колонки → перенос в эту
    группу с разрезанием целевой панели на строке drop'а.
  - Отпускание в 2-клеточном зазоре между группами → новая группа
    в этом месте.
  - Отпускание правее последней группы → добавление как новой
    последней группы.
  - Во время drag жирная линия `━` отмечает горизонтальные
    drop-зоны (resize / split в колонке), жирная `┃` —
    вертикальные (новая колонка между группами).
  - Нажатие `Escape` отменяет drag.

## Статусная строка

Статусная строка предназначена для отображения дополнительных сведений о работе в активной панели.
В зависимости от типа активной панели в ней отображаются соответствующие данные.
Прогресс фоновых файловых операций и индикатор дискового пространства прижаты
к правому краю; на узком терминале урезается собственный текст панели (с `…` в
конце), а они остаются видны.

### Индикатор дискового пространства

Справа в статусной строке отображается информация о дисковом пространстве в формате: `УСТРОЙСТВО занято/всегоГб (процент%)` с цветовой кодировкой в зависимости от уровня заполненности:

**Цветовая кодировка:**
- **Зелёный** при заполненности диска < 50%
- **Жёлтый** при заполненности диска 50-75%
- **Красный** при заполненности диска > 75%

**Формат:** `УСТРОЙСТВО занято/всего (процент%)`

Пример: `NVME0N1P2 386/467Гб (83%)`

Название устройства определяется автоматически из файловой системы:
- В Linux: показывает имена разделов как `NVME0N1P2`, `SDA1` и т.д.
- В macOS: показывает идентификатор контейнера диска (например, `DISK3`)
- Отображаемое устройство соответствует пулу хранилища, на котором находится текущая директория

В окне дисков каждая строка соответствует одному пулу хранилища, вторым столбцом указывается тип файловой системы. В macOS все тома APFS одного контейнера (`/`, `/System/Volumes/Data`, `Recovery` и т.д.) разделяют одно и то же свободное место, поэтому показываются одной строкой, а не повторяют одинаковые цифры.

### Командная палитра

`Ctrl+P` показывает все команды. Ввод фильтрует их нечётким поиском по
названию команды, её категории и сочетанию клавиш: лучшие совпадения идут
первыми, совпавшие буквы подсвечены. Например, `gitlog` находит *Open Git Log*.
Фильтр понимает синтаксис fzf: слова через пробел должны совпасть все, `'слово`
ищется буквально, `^слово` — в начале, `слово$` — в конце, `!слово` исключает.
Строчные буквы совпадают с буквами любого регистра, заглавная — только с собой.

### Окно открытия

`Ctrl+G` (или **Окна ▸ Открыть…**) запрашивает путь к файлу, каталог, URL базы
данных или адрес `http(s)://` и открывает его в подходящей панели. Клавиша
работает из любой панели, кроме двух: файловый менеджер оставляет `Ctrl+G` за
своим *переходом по пути* (с теми же подсказками), а терминал передаёт её
запущенной в нём программе. Относительный путь берётся от каталога активной
панели.

Под полем ввода список следует за набранным:

- имя (`hpprov`) нечётко сопоставляется с файлами проекта — без того, что
  игнорирует git, и без самого `.git`; лучшие совпадения первыми, синтаксис тот
  же, что у [командной палитры](#командная-палитра);
- путь (`/`, `~/`, `./`, `../`) дополняется из своего каталога, каталоги
  первыми;
- для URL списка нет.

`↑` / `↓` выбирают подсказку, `Tab` подставляет её в поле (для каталога список
затем показывает его содержимое), `Enter` открывает её — или набранный текст,
если список пуст. Щелчок по подсказке открывает её.

### Caps Lock

Termide включает [Kitty keyboard protocol](https://sw.kovidgoyal.net/kitty/keyboard-protocol/) через `KeyboardEnhancementFlags::DISAMBIGUATE_ESCAPE_CODES | REPORT_ALTERNATE_KEYS | REPORT_EVENT_TYPES`. `REPORT_EVENT_TYPES` пробрасывает `KeyEventState::CAPS_LOCK`, и матчер хоткеев использует этот бит, чтобы игнорировать «фантомный» `Shift`, который X11/Linux-терминалы навешивают на каждый буквенный event при включённом Caps Lock.

Что это даёт на практике:

- Бинты вроде `Alt+T` продолжают работать при включённом Caps Lock (без фикса event пришёл бы как `{Char('T'), Alt|Shift}` и не совпал бы с `{Char('t'), Alt}`).
- Намеренные `Shift+буква`-бинты (например, `Ctrl+Shift+F` для content-поиска) остаются отличимыми от безшифтовых версий — Shift игнорируется только если реально сообщён Caps Lock.
- Терминалы без поддержки Kitty protocol (бит Caps Lock не приходит) падают на строгое сравнение модификаторов, поведение там прежнее — лучше использовать такие терминалы с выключенным Caps Lock.

Про кодировку модифицированных стрелок и Home/End для встроенного эмулятора терминала см. [terminal.md](terminal.md#взаимодействие).
