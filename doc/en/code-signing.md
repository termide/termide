# Code Signing Policy

The Windows release binaries of Termide are signed to prevent security
warnings on Windows (SmartScreen, Smart App Control).

Free code signing provided by [SignPath.io](https://about.signpath.io/),
certificate by [SignPath Foundation](https://signpath.org/).

## Roles

- **Committers and reviewers:**
  [Members](https://github.com/orgs/termide/people)
- **Approvers (signing requests):**
  [Owners](https://github.com/orgs/termide/people?query=role%3Aowner)

## Privacy policy

Termide does not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

The coding agent connects only to the model endpoints (local or hosted) that
the user configures; no data is sent anywhere by default. Termide performs no
telemetry, no update checks and requires no account.
