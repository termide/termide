# CSV 表格查看器

Termide 将分隔符文本文件（`.csv`、`.tsv`）显示为表格：列标题、单元格网格和单元格光标，而不是原始文本。表格是只读的；要修改文件，请在编辑器中以文本形式编辑。

## 打开

- 在文件管理器中对 `.csv` / `.tsv` 文件按 **`F3`** —— 打开表格。
- **`Enter`** 或 **`F4`** —— 在编辑器中打开原始文本（与任何文本文件相同）。
- 通过打开…（`Ctrl+G`）、书签或跟随的链接打开此类文件，同样会打开表格。

文件不会被载入内存。后台扫描会找出各行的起始位置，只从磁盘读取屏幕附近的行，因此任意大小的文件都能立即打开。最前面的行一经找到就会显示。扫描进行期间，角落显示 `Loading…`，状态栏中的行数以 `…` 结尾。

## 表格 ↔ 源文本

表格和源文本编辑器是同一文件的两种视图。可在原位切换——面板被替换，而不是叠加：

- **`Ctrl+E`**（可通过 `[viewer.keybindings] toggle_view` 配置）。
- 状态栏中可点击的 **`Edit`** 标签。

源文本有未保存的更改时，无法切换回表格——请先保存。

## 文件格式

查看器会猜测两件事，显示在状态栏中，可在那里点击切换，或从面板的 `[≡]` 菜单切换：

- **分隔符** —— `,`、`;`、`Tab` 或 `|`：选择最常把开头几条记录拆分成相同字段数的那个。`.tsv` 文件始终使用 `Tab`。切换会在这四个之间循环并重新读取文件。
- **标题行** —— 第一条记录是否为列名。当它的字段都不为空且都不是数字时，就视为标题行。没有标题行时，列按电子表格的方式命名为 `A`、`B`、`C`……

带引号的字段可以包含分隔符和换行；单元格内的换行显示为 `↵`。长度不同的行按原样显示，不是有效 UTF-8 的文件读取时会替换其中的错误字节。

## 按键

| 按键 | 操作 |
|-----|--------|
| `↑` `↓` `←` `→` | 移动单元格光标 |
| `PageUp` / `PageDown` | 按屏移动 |
| `Home` / `End` | 第一个单元格 / 最后一行 |
| `s` | 按光标所在列排序：升序、降序、文件顺序 |
| `y`、`Ctrl+C` | 复制光标下的单元格 |
| `Ctrl+R` | 重新读取文件 |
| `Ctrl+E` | 切换到编辑器中的源文本 |

点击单元格会把光标移到那里；点击列标题会按该列排序，与 `s` 相同。数字按数值排序并排在文本之前；空单元格排在最后。排序会在后台再读取一遍该列：在排序完成之前，表格保持当前顺序，角落显示 `Sorting…`。面板的 `[≡]` 菜单还能复制整行（以制表符分隔），可直接粘贴到电子表格中。
