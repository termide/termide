# 应用程序窗口概览

**应用程序占据所有可用空间，垂直划分为以下元素：**
- 菜单栏
- 面板区域
- 状态栏

应用程序还使用弹出窗口：
- 帮助
- 设置
- 关闭应用确认

## 模态窗口

应用程序使用交互式模态窗口进行各种操作：
- **内嵌查找 / 替换栏**（`Ctrl+F` / `Ctrl+H`）- 停靠在编辑器、文件管理器和终端内的搜索与替换，带实时预览、匹配计数、`[Aa]` / `[.*]` 开关和导航按钮
- **输入模态框** - 用于文件操作（创建、重命名等）的各种提示
- **确认对话框** - 删除确认、未保存更改等

**模态框功能：**
- 模态框标题栏中的 `[X]` 关闭按钮（可用鼠标点击）
- 使用 Tab/Shift+Tab 进行键盘导航（在模态框字段/按钮之间）
- 所有按钮支持鼠标操作
- Escape 键关闭模态框；在选择列表、清单、输入提示、确认框或信息窗口之外单击也会同样关闭它
- 搜索/替换操作的实时预览
- 状态保持（保存上次输入的文本）

### 设置模态框（Settings）

通过 `Alt+P` 或菜单 **选项 → 编辑偏好设置** 打开。与之前的横向标签布局不同，现已改为 **侧边栏布局**：

**三个区域：**
- **左侧边栏**（宽 18 列）— 区块列表，使用 Up/Down 浏览
- **内容区**— 所选区块的字段，按 `── 分组 ──` 副标题归类并用空行分隔
- **底部按钮**— `Apply & Save`、`Reset`、`Cancel`

**侧边栏区块：**
- General、Editor、File Manager、Terminal、LSP、Logging、VFS — 普通叶节点
- **Keybindings** — 可展开分组（▶/▼），包含 7 个子区块（Global、Editor、FileManager、GitStatus、GitDiff、GitLog、Terminal）

**导航：**

| 快捷键 | 操作 |
|--------|------|
| `Up` / `Down` | 在当前区域内移动（区块 / 字段 / 按钮） |
| `Tab` / `Shift+Tab` | 在区域之间循环切换焦点（Sidebar ↔ Content ↔ Buttons） |
| `Left` / `Right` | **不** 切换区域；用于修改值（枚举循环、布尔切换）、在按键绑定行内于各按键之间移动，以及在侧边栏中折叠 Keybindings 分组 |
| `Enter` / `Space` | 激活：在侧边栏中进入区块；在内容区中切换 bool/enum 或开始编辑数值/文本；在分组头上切换展开 |
| `Escape` | 关闭模态框（Cancel） |
| 鼠标滚轮 | 滚动侧边栏 / 内容 |

**字段与指示符：**
- **Bool** — `[✓]`（开）或 `[ ]`（关），通过 `Enter`/`Space` 或 `Left`/`Right` 切换
- **Enum** — `< 值 >`，通过 `Left`/`Right` 循环
- **Number** / **OptionalText** — 按 `Enter` 进入内联编辑模式
- **LSP → Servers** — 服务器列表项以项目符号 `•` 开头；另外还有一行 `+ Add Server`

**Keybindings — 编辑绑定：**  
用 `Up/Down` 在列表中导航。每一行列出该操作接受的所有按键——`Alt+W, Alt+X, F10`——光标停在其中一个上：

| 快捷键 | 操作 |
|----------|--------|
| `Left` / `Right` | 在该行的各按键之间移动光标；越过最后一个按键时光标落到 `[+]` 按钮 |
| `Enter` | 为光标所在的槽位捕获一次按键——替换该按键，在 `[+]` 上则追加一个新的备选 |
| `Delete` | 移除光标所在的按键 |
| `Shift+Delete` / `Backspace` | 清除该操作的所有按键 |
| `Escape` | 离开列表，或放弃正在进行的捕获 |

获得焦点的行末尾画着 `[+]` 按钮：点击它，或在其上按 `Enter`，即开始捕获并把按键追加到末尾。点击某个按键会选中它，于是接下来的 `Enter` 或 `Delete` 作用于被点中的那个；双击某个按键则开始捕获。该操作已经接受的组合会被拒绝并说明原因；被其他操作占用的组合会写入，并警告它同时还绑在哪里。捕获按键期间该行仍然显示自己的按键，将被替换的那个以警告色标出。

当焦点离开侧边栏时，当前区块的高亮会取消——因为当前区块名已显示在内容区标题中，再双重高亮会让用户分不清真正的焦点位置。

## 菜单栏

菜单栏位于窗口顶部，包括：左侧的菜单项、系统资源指示器（网络速度、CPU、内存，以及有电池时的电量），以及右侧的 HH:MM 格式时钟。
菜单的激活/停用及各项目可通过鼠标点击或[键盘快捷键](#键盘导航和面板管理)访问。

**菜单项：**
- `书签` — 保存的位置（目录、文件、SSH、SFTP、网页链接）。打开时按类型路由：目录和远程路径在文件管理器中，HTML/Markdown/Mermaid/图片文件和 `http(s)` 链接在内置查看器中（见 [HTML 预览](html.md)；遵循 `[viewer] open_links`），其他文本文件在编辑器中，SSH 在终端中，数据库在 DB 查看器中。点击分组标题可切换其子菜单，与命令菜单相同。
- `命令` — 用户自定义命令，项目命令（粗体）在前，支持分组子菜单；顶部的 `添加命令...` 用于新建命令。点击分组标题展开子菜单；再次点击同一标题则折叠（toggle）。参见[自定义命令](actions.md)。
- `项目` — 项目管理子菜单：
  - 新建项目 — 在其他目录中开始项目
  - 切换项目 — 打开项目切换模态窗口（`Alt+\`）。其中的项目与下方菜单列出的方式相同，每个项目一行——标记、未打开项目最后一次使用的时间（以暗色显示）、路径和 🔔——光标所在行以反色显示。输入文字可按路径筛选列表。光标停在您最后离开的项目上：按 `Alt+\` 再按 `Enter` 即可返回该项目。`Delete`/`F8` 的作用与菜单中相同
  - 更改根路径 — 将当前项目移至其他目录

    两者都在目录树中选择目录：`→`/`←` 展开和折叠分支，`Enter` 进入目录，`Backspace` 返回上级目录，`.` 显示或隐藏隐藏目录，`Ctrl+Enter` 在任意位置确认
  - 重新打开上次运行的项目 (N) — 当上次运行中打开了不止一个项目时显示，直到您使用它或自行打开其他项目为止。它在后台打开这些项目，您仍停留在当前项目；每个项目在您第一次切换到它时加载布局，其终端中启动新的 shell。每当打开的项目集合发生变化时都会保存该列表，因此即使崩溃也不会丢失；从未打开第二个项目的运行不会改动它。同时运行多个实例时，以最后更改其项目集合的实例为准。`termide --restore`（`-r`）在启动时执行同样的操作；若没有已保存的集合，则照常启动
  - 分隔线下方列出您使用过的所有项目。先是在此实例中已打开的项目，按您安排的顺序排列：新打开的排在最后，在面板组之间移动面板的按键会移动所选项目——`Alt+PgUp`/`Alt+PgDn` 上移或下移一位，`Alt+Home`/`Alt+End` 移到开头或末尾；也可用鼠标将其拖过其他项目，拖动时按 `Esc` 则放回原处；`goto_project_N` 按此顺序编号，重新打开时也会恢复此顺序；再隔一条分隔线是其余项目，最近使用的在上；列表较长时可滚动。每行与项目切换窗口中的显示相同：标记、未打开项目最后一次使用的时间（以暗色显示）、路径（过长时截去开头）和 🔔。● 标记当前项目，○ 标记在后台打开的项目，🔔 标记有面板在等待您的项目（代理的提问或已完成的工作、终端响铃）；只要存在这样的项目，`项目` 标题后也会显示 🔔。关闭 emoji 图标时，此处和面板标题中以 `!` 代替 🔔。`Enter` 或单击即切换。`Delete`/`F8` 对后台打开的项目是关闭它并停止其中运行的程序，对未打开的项目是删除其已保存的布局并将其从列表中移除（项目文件不受影响）；两者都会先请求确认。对当前项目，则切换到您最后离开的项目并关闭当前项目，仅当其中有正在运行的程序或未保存的更改时才请求确认；若没有其他已打开的项目，当前项目不受影响
  - 切换到其他项目时，原先所在的项目会在后台保持打开：其终端中的程序继续运行，代理继续工作，未保存的修改保持原样。项目会一直保持打开，直到您关闭它或 TermIDE 退出。对已打开的目录执行“新建项目”会切换到该目录。退出时 TermIDE 会列出仍在运行程序的后台项目。`prev_project`、`next_project` 和 `goto_project_1`…`goto_project_9` 可用键盘在已打开的项目之间切换；它们默认未绑定，参见[未绑定的操作](keybindings.md#未绑定的操作)
- `AI` — 编码代理的代理、会话、技能和提示词，以及代理浏览器窗口的开关；参见 [AI 菜单](agent.md#ai-菜单)
- `窗口` — 面板创建子菜单：
  - 打开… — 通过带建议的提示打开文件、目录或 URL（`Ctrl+G`）
  - 终端 — 终端面板（有子菜单可选择 shell：列出系统中所有可用的 shell，默认 shell 以 ● 标记）
  - 文件 — 文件管理器面板
  - 编辑器 — 文本编辑器面板
  - Git 状态 — Git 状态面板
  - Git 日志 — 提交历史面板
  - 日志 — 应用日志面板
  - 诊断 — LSP 诊断面板
  - [操作](operations.md) — 后台操作面板
  - 大纲 — 代码结构导航面板
  - [代理](agent.md) — 编码代理面板
- `选项` — 设置子菜单：
  - 主题 — 主题选择（实时预览）
  - 语言 — 界面语言（实时预览）
  - 编辑偏好设置 — 打开设置模态框
  - 帮助 — 打开帮助面板
  - 分离实例 — 让本实例在后台继续运行（仅在可分离时显示；参见[可分离实例](detached-instances.md)）
  - 退出 — 退出应用

**系统资源指示器**（可点击的指示器会打开详情模态框）：

| 指示器 | 说明 | 点击打开 |
|--------|------|---------|
| `↓…/↑…` | 网络速度（↓ 下载，↑ 上传） | 网络活动前 10 的进程 |
| `CPU XX%` | CPU 使用率 | CPU 占用前 10 的进程 |
| `RAM X/YGB` | 内存使用 | 内存占用前 10 的进程 |
| `⚡NN%` / `🔋NN%` | 电池电量（⚡ = 已接通电源 / 充电中 / 已充满，🔋 = 使用电池）。没有电池的系统上隐藏。 | —（仅显示信息） |
| `设备 已用/总计GB`（状态栏） | 磁盘使用 | 磁盘占用前 10 的进程 + 文件系统分区 |

再次点击同一指示器会关闭其打开的窗口（toggle）；状态栏的磁盘指示器行为相同。

颜色编码（CPU / 内存）：绿色 < 50%，黄色 50–75%，红色 > 75%。电池使用反向的同一刻度（充电中或高于 50% 为绿色，低于 25% 为红色）。电池读数缓存 5 秒，因此每帧渲染路径从不访问 `/sys`。

**网络活动模态框**显示：
- **Application** — 进程名
- **Ports** — 监听的 TCP 端口（例如 `80, 443`）
- **Conn** — 活动（ESTABLISHED）连接数

进程按连接数从多到少排序。

## 面板区域

面板区域填充菜单栏和状态栏之间的垂直空间，从左到右延伸至窗口边缘。
布局会根据终端宽度自适应，在更宽的屏幕上显示更多面板组。面板（终端、编辑器、Git）可以打开并排列在旁边。

**可打开的面板类型：**
- [文件管理器](file-manager.md) — `Alt+F`
- [终端](terminal.md) — `Alt+T`
- [文本编辑器](editor.md) — `Alt+E`
- Git 状态 — `Alt+G`
- 大纲 — `Alt+O`
- 诊断 — `Alt+I`
- Git 日志 — `Alt+C`
- Git 差异
- [编码代理](agent.md) — `Alt+A`
- [操作](operations.md)
- 图片查看器
- 帮助 — `Alt+H`
- 日志 — `Alt+L`

**Git 状态**面板顶部有两个选择器：仓库和分支。分支列表包含本地分支，以及没有对应
本地分支的远程分支；`●` 标记在仓库主副本中检出的分支，`⧉` 标记在关联工作树
（worktree）中检出的分支（工作树目录不会作为独立仓库列出）。选择分支永远不会检出
它——只会改变面板显示的内容：

- 在主副本或某个工作树中检出的分支，显示该工作副本的更改，暂存、提交、diff、
  推送和拉取都在其中执行；
- 未在任何地方检出的分支，显示它相对主副本分支领先和落后多少，并带有 `[Checkout]`
  按钮，可将其检出到主副本。当 git 拒绝时（例如有未提交的更改挡路），其消息会作为
  错误显示。

`[Log]` 在同一仓库和分支上打开 Git 日志。日志自己的分支选择器以同样方式标记分支，
只用于选择显示哪条历史；检出之后，跟随 HEAD 的日志会切换到新分支。

**Git 日志**面板根据每个提交的父提交，用制表符伪图形（`● │ ├ ╮ ╯`）绘制提交图，
每条线各有颜色，便于按颜色追踪分支。如需改回 git 原生的 ASCII `--graph`，请在
`config.toml` 中设置：

```toml
[git_log]
unicode_graph = false
```

日志在滚动时读取历史：最初的提交会立即显示，当视图下方剩余不足两屏时会继续读取，
期间在最后一个提交下方显示 *Loading commits…* 行。`End` 会读到历史末尾（无论多长），
并在读取过程中保持选中最后一个提交。滚动条从一开始就覆盖整个历史。当日志重新加载时
——提交、检出、变基之后——选中的提交保持选中，并停留在屏幕上的同一位置。

打开**二进制文件**（在文件管理器中按 `Enter` 或 `F3`）会显示只读的**十六进制查看器**
——`偏移 │ 十六进制 │ ASCII`，行宽按 16 字节分段适应面板——而不是交给系统查看器。
十六进制区和 ASCII 区都显示字节光标（`Tab` 切换活动区）；方向键/`hjkl` 移动光标，
`Shift`+移动进行选择，`Ctrl+C` 复制选区（在十六进制区复制为十六进制，在 ASCII 区
复制为文本）。`Ctrl+F` 打开搜索栏，搜索 ASCII 子串，或——开启 `[hex]` 开关时——
搜索 `ff fe` 这样的十六进制字节序列；匹配项在两个区中都会高亮。

改用 `F4`（编辑）打开二进制文件则使其**可编辑**：输入会覆盖光标下的字节——在十六进制
区输入两个十六进制半字节，在 ASCII 区输入一个字符——而不改变文件长度。未保存的编辑
会在标题中显示 `*`；`Ctrl+S` 经确认后保存，保存前先将原文件备份为 `<file>.bak`。

`Ctrl+L`（或状态栏中的 `[Hex]`/`[Text]` 标签）在十六进制和文本之间切换。对于真正的
文本文件，这会将面板原地替换为只读编辑器（编辑器自己的 `Ctrl+L` 可切换回十六进制）；
对于编辑器无法以文本打开的二进制文件，则切换为面板内的有损文本视图。该切换键可配置：

```toml
[viewer.keybindings]
toggle_hex = "Ctrl+L"
```

**可关闭面板的特点：**
- 面板标题中有 `[≡]` 操作按钮（点击打开上下文菜单：关闭 / 拆分 / 合并 / 移动）
- 可通过 Escape、Alt+W、Alt+X 或 F10 关闭
- 列宽通过 `Alt+=` / `Alt+-` 调整
- 列内每个面板的高度通过 `Alt+Shift+=` / `Alt+Shift+-`（步长 1 行）、用鼠标拖动面板的下边框或在列内上下拖动面板标题进行调整
- `Alt+F11` 切换聚焦面板的全屏预设（一个面板占满整列，其余各自缩为一行标题）；再次按下恢复之前的高度
- 有些面板按内容自适应高度，而不是分得列的一份——操作面板就是其中之一——并在全屏预设期间保持该高度（聚焦这类面板时，已放大的面板保持原样）；手动调整这类面板的大小会让它获得普通的固定高度，直到它被关闭
- 可通过拖拽顶部边框来移动（参见下面的"鼠标交互"）

**面板操作上下文菜单：**

点击面板标题中的 `[≡]` 按钮（或在活动面板上按 `Alt+K` / `Shift+F10`）会打开下拉菜单：
- **上移 / 下移** — 在当前组内重新排序（当组内有多个面板时）
- **左移 / 右移** — 移动到相邻组（当有多个组时）
- **拆分 / 合并** — 从组中拆分出新组（当堆叠时），或将单独面板与相邻组合并
- **关闭** — 关闭面板（必要时带确认）

菜单项根据上下文过滤：例如，只有一个面板在一个组中时，*拆分/合并* 隐藏；单独面板时，*上移/下移* 隐藏。

**鼠标交互：**
- 点击标题区域激活面板；双击文件管理器标题打开目录选择器。
- **拖拽滚动条滑块**（面板右边框上的 `▌` 块，或绘有水平滚动条时下边框上的 `━` 块）
  可将面板滚动到对应位置。只有滑块会被这样抓取：滚动条轨道以及没有滚动条的边框仍按
  下文所述调整布局。拖拽未聚焦面板的滑块会原地滚动它而不移动焦点，与鼠标滚轮相同。
- **拖拽面板的底部边框** 在列内调整该面板的高度（实时 `━` 幽灵线
  预览新分隔线的位置，调整在释放时应用）。
- **拖拽面板的顶部边框（标题）** —— resize 或 reorder：
  - 在源面板主体或上方相邻面板的主体内释放 → 垂直 resize：
    被拖面板上方的分隔线跟随光标（列顶部的面板上方没有分隔线，
    会回退到移动模式）。
  - 在同组另一个面板的标题行上释放 → 重新排序：根据方向插入
    到目标的前面 / 后面。
  - 在另一列面板的主体上释放 → 移动到该组，并在 drop 行处分割
    目标面板。
  - 在两个组之间的 2 格间隙释放 → 在该位置创建新组。
  - 在最右组之外释放 → 作为新的最后一组追加。
  - 拖拽过程中，粗 `━` 线标记水平 drop 区（列内 resize / split），
    粗 `┃` 线标记垂直 drop 区（组之间的新列）。
  - 拖拽过程中按 `Escape` 取消。

## 状态栏

状态栏用于显示活动面板的附加工作信息。
根据活动面板的类型，显示相应的数据。
后台文件操作的进度和磁盘空间指示器靠右对齐；在较窄的终端中，面板自身的文本会被截断并以 `…` 结尾，以保证这些内容始终可见。

### 磁盘空间指示器

状态栏在右侧显示磁盘空间信息，格式为：`设备名 已用/总计GB (使用率%)`，根据使用水平进行颜色编码：

**颜色编码：**
- **绿色** 磁盘使用率 < 50%
- **黄色** 磁盘使用率 50-75%
- **红色** 磁盘使用率 > 75%

**格式：** `设备名 已用/总计 (使用率%)`

示例：`NVME0N1P2 386/467Gb (83%)`

设备名称从文件系统自动检测：
- Linux 上：显示分区名称，如 `NVME0N1P2`、`SDA1` 等
- macOS 上：显示磁盘容器标识符（例如 `DISK3`）
- 显示的设备对应当前目录所在的存储池

磁盘窗口每个存储池一行，第二列为文件系统类型。在 macOS 上，同一容器的所有 APFS 卷（`/`、`/System/Volumes/Data`、`Recovery`……）共享同一可用空间，因此合并为一行报告，而不是重复相同的数字。

### 命令面板

`Ctrl+P` 列出所有命令。输入内容会按命令名称、类别和快捷键进行模糊匹配过滤，最佳匹配
在前，匹配的字母高亮显示：`gitlog` 会找到 *Open Git Log*。过滤器采用 fzf 语法——以
空格分隔的多个词必须全部匹配，`'word` 按字面匹配，`^word` 匹配开头，`word$` 匹配
结尾，`!word` 表示排除。小写字母匹配任意大小写；大写字母只匹配其本身。

### 打开提示

`Ctrl+G`（或 **窗口 ▸ 打开…**）要求输入文件路径、目录、数据库 URL 或 `http(s)://`
地址，并在对应的面板中打开。它在除两种面板外的所有面板中都可用：文件管理器将 `Ctrl+G`
留给自己的*转到路径*（提供相同的建议），终端则将其传给其中运行的程序。相对路径以
聚焦面板的目录为基准。

输入框下方的列表随输入而变化：

- 名称（`hpprov`）会与项目中的文件进行模糊匹配——git 忽略的文件和 `.git` 本身除外
  ——最佳匹配在前，语法与[命令面板](#命令面板)相同；
- 路径（`/`、`~/`、`./`、`../`）从其所在目录补全，目录在前；
- URL 不显示列表。

`↑` / `↓` 选择建议，`Tab` 将其填入输入框（目录随后会列出其内容），`Enter` 打开它
——列表为空时则打开输入的文本。单击可直接打开某个建议。

### Caps Lock

Termide 通过 `KeyboardEnhancementFlags::DISAMBIGUATE_ESCAPE_CODES | REPORT_ALTERNATE_KEYS | REPORT_EVENT_TYPES` 启用 [Kitty 键盘协议](https://sw.kovidgoyal.net/kitty/keyboard-protocol/)。`REPORT_EVENT_TYPES` 会在每次按键事件中附带 `KeyEventState::CAPS_LOCK`，热键匹配器据此忽略 X11/Linux 终端在 Caps Lock 开启时强行附加的虚假 `Shift` 修饰符。

实际效果：

- 开启 Caps Lock 时 `Alt+T` 这类绑定依然生效（否则事件到达时是 `{Char('T'), Alt|Shift}`，无法匹配 `{Char('t'), Alt}`）。
- 真正的 `Shift+字母` 绑定（例如 `Ctrl+Shift+F` 用于内容搜索）仍与无 Shift 版本区分清楚——只在真的报告了 Caps Lock 时才剥离 Shift。
- 不支持 Kitty 协议的终端（不发送 Caps Lock 位）会回退到严格的修饰符比较，行为保持不变——在这些终端中建议关闭 Caps Lock 使用。

内嵌终端模拟器的方向键和 Home/End 的修饰编码见 [terminal.md](terminal.md#交互操作)。
