# 代码签名政策

Termide 的 Windows 发布版二进制文件经过签名，以免在 Windows 上触发安全警告
（SmartScreen、Smart App Control）。

免费代码签名由 [SignPath.io](https://about.signpath.io/) 提供，证书来自
[SignPath Foundation](https://signpath.org/)。

## 角色

- **提交者和审阅者：**
  [成员](https://github.com/orgs/termide/people)
- **批准者（签名请求）：**
  [所有者](https://github.com/orgs/termide/people?query=role%3Aowner)

## 隐私政策

除非用户或安装、运行它的人明确要求，Termide 不会向其他联网系统传输任何信息。

编码代理只连接用户配置的模型端点（本地或托管）；默认情况下不会向任何地方发送数据。
Termide 不收集遥测数据，不检查更新，也不需要账户。
