# 文件管理器

文件管理器面板提供直观的界面，用于浏览文件系统和执行文件及目录操作。

远程文件系统（SFTP / FTP / FTPS）与本地路径在同一面板中显示——
URL 语法和认证配置请参见[远程文件系统](vfs.md)。ZIP 和 tar 压缩包像只读目录一样打开——参见[压缩包](vfs.md#压缩包)。

## 导航

| 快捷键 | 操作 |
|-------------------|--------------------------------------------|
| `↑` / `↓`         | 上下移动光标                               |
| `Enter`           | 进入目录或压缩包、预览媒体或打开文件       |
| `Backspace`       | 转到上级目录                               |
| `~`               | 转到主目录                                 |
| `PageUp` / `PageDown` | 按页滚动列表                          |
| `Home` / `End`    | 转到列表开头/末尾                          |
| `.`               | 切换隐藏文件可见性                         |
| `→` / `l`       | 展开目录（树形视图）                        |
| `←` / `h`       | 折叠目录（树形视图）                        |
| `/`              | 树内增量搜索                                |
| `Ctrl+\`          | 打开目录切换器                             |
| `Ctrl+G`          | 转到路径/URL，带[建议](ui.md#打开提示)；文件会在其所在目录中被选中 |
| `Alt+B`           | 添加书签                                   |
| `Tab`             | 转到下一个面板                             |
| `Shift+Tab`       | 转到上一个面板                             |

在 Windows 上，目录切换器还会列出所有驱动器。在驱动器或网络共享的根目录没有上级目录可去，因此 `..` 和 `Backspace` 在那里会改为打开目录切换器。

## 文件选择

| 快捷键 | 操作 |
|-------------------|--------------------------------------------|
| `Insert`          | 切换当前文件的选择状态                     |
| `Shift + ↑ / ↓`   | 选择多个连续文件                           |
| `Ctrl+A`          | 选择面板中的所有文件和目录                 |
| `Escape`          | 清除所有选择                               |

在树形视图中，使用 `Insert` 选择目录会级联选择其中的所有文件。折叠已选择的目录时，其子元素的选择状态会保留。

## 文件操作

| 快捷键 | 操作 |
|-------------------|--------------------------------------------|
| `Ctrl+N`          | 创建新文件                                 |
| `D` / `F7`        | 创建新目录                                 |
| `Delete` / `F8`   | 删除选中的文件/目录                        |
| `C` / `F5`        | 复制选中的文件/目录                        |
| `M` / `F6`        | 移动/重命名文件/目录                       |
| `P`               | 将所选文件/目录打包为[压缩包](vfs.md#打包) |
| `E` / `F4`        | 在编辑器中打开文件                         |
| `R` / `F2`        | 重命名文件/目录                            |
| `V` / `F3`        | 查看文件（预览而不执行）                   |
| `Ctrl+R`          | 刷新当前目录内容                           |
| `Space`           | 显示文件/目录信息                          |

复制和移动可以像双栏文件管理器那样在面板之间进行：在第一个文件管理器旁边再打开
一个，在其中一个里选中文件，然后按 `C` / `F5` 或 `M` / `F6`。目标路径预先填入
最近的另一个文件管理器的目录（没有时使用其他面板的目录）；只有当所有面板都位于源目录时
才会预填源目录。当面板位于多个不同目录时，输入框下方会出现列出所有这些目录的下拉列表；
路径仍可编辑。

## 搜索

| 快捷键 | 操作 |
|-------------------|--------------------------------------------|
| `Ctrl+F`          | 按名称搜索文件（glob 模式）               |
| `Ctrl+Shift+F`    | 在文件内容中搜索                           |
| `Ctrl+Shift+H`    | 在文件内容中搜索并替换                     |
| `/`              | 树内增量搜索（边输入边过滤）                |

这些搜索都使用**停靠在面板底部的内嵌栏**（而非浮动模态框），其上带标题边框（`─ Find ─`）将其与上方结果隔开。
栏与结果是两个**区域**：`Tab` 在它们之间切换（与 Git 状态面板一致）。在栏区域，
方向键在字段与开关间移动。在结果区域，光标落在**条目行**（文件/文件夹，或文件
标题）上，与 diff 面板一致：`↑` / `↓` 在它们之间移动，`PageUp` / `PageDown`
翻页，`←` / `→` 折叠 / 展开光标处的条目，`Enter` 打开它（文件夹/标题则折叠或
打开）。鼠标单击选择行，双击打开（或折叠分组），滚轮滚动。`Esc` 退出搜索
（不会关闭面板）。

### 文件搜索 (Ctrl+F)

内嵌栏，仅含一个 `Find:` 字段，实时按 glob 过滤文件；结果（带 Git 状态颜色的
相对路径）以树形显示在分隔线下方。`Tab` 进入结果；`↑` / `↓` 在文件**和文件夹**
间移动，`←` / `→` 折叠 / 展开文件夹，`Enter` 打开文件（并在树中将光标置于其上）。

默认匹配为**不区分大小写的子串**；`[Aa] Case` 与 `[.*] Regex` 开关可改变它：
`[Aa]` 启用区分大小写，`[.*]` 将查询作为针对文件名的正则表达式（点击开关，或将
焦点移到开关上并按 `Enter` / `Space`）。

`Ctrl+R` 针对当前目录内容重新运行搜索。

### 内容搜索 (Ctrl+Shift+F)

内嵌栏，含 `Find:`（glob 掩码，默认 `*`）与 `Text:`（内容查询）字段：
- 默认按**字面**匹配；`[.*] Regex` 切换为正则表达式，`[Aa] Case` 切换大小写
  敏感（点击，或聚焦开关后按 `Enter` / `Space`）。
- 仅搜索文本文件（跳过二进制文件）；跳过大文件（可在设置中配置限制）。
- 结果在分隔线下方**按文件分组**，与 diff 面板一致：光标在**文件标题**间移动
  （`[▼]`/`[▶]` 折叠标记 + 路径 + 匹配数），每个文件下最多显示 5 行匹配（行号 +
  高亮匹配行），超出则显示 `+ N more` 行。`←` / `→` 折叠 / 展开文件，`Enter`
  在其首个匹配处打开。

### 内容替换 (Ctrl+Shift+H)

`Ctrl+Shift+H` 打开同一内容栏，并多出一个 `Repl:` 字段。输入替换文本后，每个
显示的匹配都会渲染为 `-旧/+新` 预览。

每个文件标题都有一个**选择复选框**（折叠三角右侧的 `[ ]`），替换**只作用于已
勾选的文件**——默认不勾选任何文件。用 `Space` 或点击切换光标处文件；**`[ ] Select all`** 复选框（或 `a`）
一次性全选/全不选。栏右侧实时显示
`已选 / 总文件 · 替换数` 计数。

在 `Repl:` 字段按 `Enter`（或激活 **Replace** 按钮）即可替换**已勾选**文件中的
全部匹配——会先确认替换的处数与文件数（未选择时显示提示）。开启 `[.*] Regex`
时替换支持 `$1` / `${name}` 捕获组；否则按字面插入。替换会写入磁盘。

### 树内搜索 (/)

按 `/` 在当前目录树中进行增量搜索：
- 输入时实时过滤文件列表，仅显示匹配项
- 匹配文件的父目录保持可见以提供上下文
- 按 `Enter` 确认并导航到匹配项
- 按 `Escape` 取消并恢复完整树
- 与树形视图协同工作 — 包含匹配项的目录自动展开

## 剪贴板

| 快捷键 | 操作 |
|-------------------|--------------------------------------------|
| `Ctrl+C`          | 将选中项作为文件复制                       |
| `Ctrl+X`          | 剪切选中项                                 |
| `Ctrl+V`          | 粘贴——若剪贴板中是剪切的内容则移动        |
| `Cmd+V` (macOS)   | 粘贴在 termide 中复制的文件                |

在 macOS 上，`Cmd+V` 由终端模拟器自己处理：它把剪贴板中的*纯文本*直接
输入面板，termide 并不会收到粘贴事件。当这些输入的文本指向真实存在的文件
时，文件管理器会将其识别为文件粘贴——termide 自己的复制会在文件之外同时
携带路径，因此 `Cmd+V` 能够粘贴它们。来自其他应用的复制会怎样，取决于该
应用是否也向剪贴板写入纯文本；`Ctrl+V` 始终直接读取文件列表，因此更为可靠。
粘贴普通文本时仍按普通文本处理。

### 剪贴板中的内容

`Ctrl+C` 写入**原生文件列表**（macOS 上为 `NSPasteboardTypeFileURL`、
Windows 上为 `CF_HDROP`、Linux 上为 `text/uri-list`），因此在访达、资源管理器
或邮件撰写窗口中粘贴的是文件本身，而不是路径字符串。

有三点值得注意：

- **`Ctrl+X` 写入与 `Ctrl+C` 相同的列表。** 没有任何系统剪贴板格式为文件
  携带“已剪切”标记，termide 无法告知访达或资源管理器这些文件应当移动。
  它们会粘贴出*副本*而原件留在原处——弄错在这个方向上是安全的：多余的
  副本一条 `rm` 就能清掉，被删的原件却无从找回。真正的移动发生在 termide
  内部，由面板记住剪切的到底是什么。
- **远程与归档内的条目仍为文本。** `file://` URL 无法指向 SFTP 或归档内
  的条目，这些面板继续复制路径字符串。
- **符号链接仍为文本。** 文件类型会向系统索取真实路径，写入的链接会以
  *目标*及其名称送达。选中项含符号链接时按文本复制路径，链接本身得以保留。
  若要在目标处创建链接，请使用复制对话框（`C` / `F5`）中的“Create symlink”。

只要平台允许，复制会在文件之外同时携带纯文本类型，因此浏览器地址栏、
其他终端或终端模拟器自身的 `Cmd+V` 得到的是路径而不是空白。在 Linux 上，
文件类型会完全占据剪贴板，复制文件时纯文本使用者什么都得不到；在 termide
内部，各文本界面会把文件列表按换行拼接为路径读回，因此在编辑器、终端、
agent 输入框或输入对话框中粘贴仍能得到可用的路径。

粘贴确认框会在目标目录之上列出即将写入的文件名——最多三个，其后是折叠的
`… N`——从而说明落地的具体是哪些文件，而不仅是数量。

通过 SSH 或在没有显示服务的主机上，文件类型不可用，复制会退回路径文本。

### 剪切与粘贴

剪切意味着移动：`Ctrl+X` 之后 `Ctrl+V` 会把文件放到目标位置，并从原来所在
处删除。确认框会直接说明这一点——是“移动 N 个文件到：”，而不是“复制”——
因为按下“是”删除的就是源文件。

剪切的记忆只在剪贴板仍然保存着它时有效。此后再复制任何内容——无论在
termide 内还是其他应用中——都会让下一次粘贴退回复制；在 macOS 上由剪贴板
的变更计数决定，其他平台则比较路径本身。取消确认会保留剪切，因此你可以
改变目标位置后再次粘贴。

`Ctrl+X` 在远程面板与归档内会拒绝执行并说明原因：那里没有可移动的东西，
而交出一份粘贴时变成复制的“剪切”，正是剪切最不该做的事——要么悄悄删除，
要么假装移动。

### 目标目录规则

新建文件、新建目录和从剪贴板粘贴都会**落在光标所在的树层级**，并非
总是落在面板根目录：

- 光标在顶层条目上 → 操作目标为面板的当前目录。
- 光标在展开的子目录内 → 操作目标为该子目录。
- 光标在已展开的目录本身上 → 操作目标为该目录，即其可见子项所在处。

这符合光标的视觉位置——所见即所建/所贴位置。

## Git 集成

文件管理器显示 Git 仓库中的文件状态：

- **文件状态颜色** — 新增、修改、删除和未跟踪的文件以不同颜色标识
- **嵌套 Git 状态** — 目录显示其子元素的聚合状态（例如，包含修改文件的目录会被高亮显示）
- **树形视图集成** — Git 状态在目录树中传播，便于在深层层次结构中定位更改

## 媒体预览

文件管理器可以使用控制台图片查看器预览图片和视频。

**文件打开逻辑：**

| 文件类型 | 操作 |
|-----------|--------|
| 光栅图片（PNG、JPG、JPEG、GIF、WebP、BMP、TIFF） | ImagePanel（原生图形）或 xdg-open 回退 |
| 矢量图片（SVG、ICO） | xdg-open（系统查看器） |
| 视频（MP4、MKV、AVI、MOV、WebM、FLV、WMV、M4V） | xdg-open（系统播放器） |
| 二进制文件 | xdg-open（系统默认） |
| 文本文件 | 编辑器面板 |
| 可执行文件 | 在终端中运行 |

**快捷键：**
- `Enter` → 智能打开（参见上表）
- `F3` → 查看文件（类似 Enter，但可执行文件在编辑器中打开而非运行）
- `O` / `Alt+Enter` → 强制使用 xdg-open（系统默认应用程序）打开
- `F4` → 始终在编辑器中打开

**原生图形：**
termide 自动检测父终端是否支持图形协议（Kitty、Sixel、iTerm2）。支持时，光栅图片直接在 ImagePanel 中渲染，无需外部工具。

图片打开时适应面板：按宽度或高度尽可能放大，保持比例并居中。`+` / `-`（或面板上的鼠标滚轮）围绕可见部分的中心放大和缩小，方向键平移放大后的图片，`0` 恢复适应视图。状态栏显示图片尺寸和当前缩放比例（相对于原始像素的百分比），以及可点击的 `[−]`、`[+]` 和 `Fit` 按钮。

**支持的终端：**
- Kitty、WezTerm、iTerm2、Ghostty、foot - 完整图形支持
- 其他终端 - 回退到 xdg-open

## 鼠标支持

- **单击**：选择文件或目录
- **双击**：进入目录或打开文件
- **滚轮**：滚动文件列表

## 显示

### 字体修饰

- **斜体** — 符号链接（文件和目录）
- **粗体** — 可执行文件

### 排序顺序

文件按分组显示，每组按字母顺序排列：
1. 目录
2. 可执行文件
3. 普通文件

### 符号链接

- 复制模态框包含"创建符号链接"复选框 — 创建符号链接而非复制
- 进入符号链接目录时，文件管理器跟随链接进入目标目录
- 在符号链接上按 `Space` 打开属性模态框，其中包含 **Target** 行，显示链接中实际写入的路径（未经 `canonicalize` 解析），并将用户主目录缩写为 `~`
- 状态栏会在当前选中符号链接的文件名后显示 `→ target`；该行为同样适用于展开子目录树视图中的嵌套符号链接

### 备注

- `..`（上级目录）不可选择 — 仅用于导航
- 输入模态框支持将 `~/` 展开为主目录
- 状态栏为光标所在项显示 **Size:** 字段（位于 **Owner:** 右侧）：文件显示字节大小，目录显示 `<大小> (N 项)` —— 即递归大小加上直接（非递归）子项数量。子项数量立即显示，递归大小随计算完成而填充。属性模态框（`Space`）的 **Size** 行也显示相同内容（例如 `1.2 MB (42 项)`）。

## 配置

文件管理器从 `config.toml` 中的 `[file_manager]` 节读取设置。主要的
用户可见选项：

| 键                                  | 默认值   | 说明                                                                                                          |
|-------------------------------------|----------|---------------------------------------------------------------------------------------------------------------|
| `extended_view_width`               | `50`     | 面板宽度（列数）达到该值时 extended view 会显示大小/修改时间列。                                              |
| `content_search_max_file_size_mb`   | `1`      | `Ctrl+Shift+F` 内容搜索考虑的最大文件大小，超过则跳过。                                                       |
| `dir_size_in_wide_view`             | `true`   | 在 extended view 的 Size 列计算并显示目录大小。仅适用于本地文件系统。                                         |
| `dir_size_budget_ms`                | `100`    | 单个目录扫描的时间预算（毫秒）。超过预算的目录显示 `-`。设为 `0` 则关闭该功能。                                |

扫描结果保存在进程级共享缓存中，两个查看同一目录的面板不会重复扫描。
在目录上按 `Space` 也会把它的精确（完整）大小发布到该缓存——下一帧
重绘时 wide view 的大小列会读取该结果。
