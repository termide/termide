# 数据库查看器

TermIDE 内置了一个数据库浏览器，支持 **SQLite**、**PostgreSQL** 和
**MySQL/MariaDB**。它通过原生协议连接（无需外部客户端工具），列出数据库的表，
并在可滚动的表格中显示行，支持排序和按列过滤。

浏览时只执行 `SELECT` 和目录查询。值可以编辑（参见[编辑值](#编辑值)）；在你
动手编辑之前不会写入任何内容——SQLite 文件甚至以只读方式打开，直到第一次编辑
时才重新以写入方式打开。

## 打开连接

连接就是路径为数据库 URL 的普通**书签**。添加书签（书签菜单 → 添加），并在*路径*
字段中填入连接 URL：

| 引擎 | URL 示例 |
|------|----------|
| SQLite | `sqlite:///absolute/path/to/app.db` |
| PostgreSQL | `postgres://user@host:5432/mydb` |
| MySQL / MariaDB | `mysql://user@host:3306/mydb` |

激活数据库书签会打开数据库面板并在后台连接——连接时界面不会阻塞。

无需书签也有两种打开数据库的方式：

- **直接打开本地 SQLite 文件。** 在文件管理器中对 `.db` / `.sqlite` /
  `.sqlite3` / `.db3` 文件按 `Enter` 或 `F3`——它会在数据库查看器中打开，而不是
  十六进制查看器。
- **Windows ▸ Open…**（或 `Ctrl+G`）接受连接 URL（`sqlite://` /
  `postgres://` / `mysql://`），也接受文件路径、目录或 `http(s)://` 地址，并
  路由到匹配的查看器。

### 密码

不要把密码写进 URL。服务器拒绝登录时，面板会从[密码库](passwords.md)中取得密码或
询问它，并提供一个复选框将其保存到密码库。密码永远不会成为面板 URL 的一部分，因此
已保存的布局中不含密码。

免密码的认证方式（PostgreSQL 的 `~/.pgpass`/peer/trust、Unix 套接字、
`PGPASSWORD` 等）照常可用。写入 URL 的密码（`postgres://user:secret@host/db`）
仍会被使用。将这样的 URL 保存为书签时，TermIDE 会提议将密码移入密码库。

## 布局

```
┌─ Database ──────────────────────────────────────────┐
│ Table ▾ users                                        │
│ id │ name  │ score │ active                          │
│  1 │ alice │ 1.5   │ true                             │
│  2 │ bob   │ 2.25  │ false                            │
│  3 │ carol │ NULL  │ true                             │
└──────────────────────────────────────────────────────┘
```

顶部是**表选择器**，其余部分是**数据表格**。当连接 URL 未指定数据库时
（PostgreSQL/MySQL），其左侧会出现**数据库选择器**；查看器会自动选择第一个数据库
以便立即显示数据，你也可以通过该选择器切换到其他库。表格有一个二维单元格光标：
高亮的单元格
是排序、过滤和复制的目标。右侧的**垂直滚动条**显示你在整张表中的位置（跨页），当
列宽超过面板时底部会出现**水平滚动条**。共享状态栏显示当前范围、总行数、当前排序和
过滤，例如：`app.db · users · rows 1–200 of 1203 · sort: name ↑ · filter: 1`。

## 按键

| 按键 | 操作 |
|------|------|
| `Tab` | 在表选择器和表格之间切换焦点 |
| `Enter` / `Space`（在选择器上） | 打开表下拉列表 |
| `↑ ↓ ← →` | 移动单元格光标（自动滚动行和列） |
| `PageUp` / `PageDown` | 翻一屏；到边缘时加载下一/上一个窗口 |
| `Home` / `End` | 跳到第一行 / 最后一行 |
| `S` | 按当前列排序——循环：升序 → 降序 → 不排序 |
| `Ctrl+F` / `F3` | 过滤当前列（打开过滤对话框） |
| `Alt+F` | 清除所有过滤 |
| `Enter`（在表格上） | 就地编辑当前单元格（`Enter` 保存，`Escape` 放弃） |
| `Space` / `F12`（在表格上） | 打开行对话框：编辑任意值，或复制该行 |
| `Ctrl+C` | 复制当前单元格的值 |
| `Ctrl+Y` | 将当前行复制为制表符分隔的值 |
| `Ctrl+R` | 刷新表列表并重新加载当前视图 |

这些操作键可在配置的 `[database.keybindings]` 中自定义，并显示在帮助面板中。
导航键（Tab、方向键、PageUp/Down、Home/End）是固定的。

**鼠标：** 点击表选择器将其打开，点击列标题切换其排序，点击数据单元格将光标移到该处。

## 排序

在某列上按 `s` 进行服务端排序。循环为**升序 → 降序 → 不排序**；“不排序”不发出
`ORDER BY`，在大表上开销最小。已排序的列在表头显示 `↑`/`↓` 箭头。一次只排序一列。

> 在 PostgreSQL 上，翻阅*未排序*的表时，各页之间的行顺序可能略有不同（引擎的自然
> 顺序在 `OFFSET` 之间不稳定）。如需稳定顺序，请应用排序。

## 过滤

`Ctrl+F`（或 `F3`）打开过滤对话框，其中列出**每一列**——每列一行：列名、**运算符
选择框**和值。在一行内，←/→ 在运算符和值之间切换焦点，↑/↓ 在行之间移动；在运算符
上按 Enter 打开其下拉列表（第一个选项表示“无条件”）。可用的运算符取决于列的类型：

- **文本：** 包含、以…开头、以…结尾、=、≠、为空、不为空
- **数字 / 日期：** =、≠、>、≥、<、≤、为空、不为空
- **布尔：** =、≠、为空、不为空

若该列仍为 `—`，输入值会自动选择一个默认运算符，所以可以直接输入。底部按钮：
**应用**、**清除过滤**、**取消**。应用会替换整个过滤集；不同列上的条件以 **AND**
组合；没有值的运算符会被忽略。`包含`/`以…开头`/`以…结尾` 不区分大小写。`Alt+F`
不打开对话框即清除所有过滤。值始终作为绑定参数发送；若过滤导致数据库错误（例如对
数字列使用非数字值），它会作为非致命警告显示在状态栏，当前数据保持不变。

## 行详情与编辑

在某行上按 `Space` 打开行对话框：每一列独占一行，完整显示其值——适用于长文本、
JSON 或表格放不下的宽行。值可在此处编辑，对话框还可将该行复制为 **TSV**、
**JSON** 或 **INSERT** 语句。

用 `Tab` / 方向键在字段之间移动，输入即可修改值，按 `Enter` 跳到按钮栏——然后
`Save` 会写入所有已更改的列。接受 NULL 的列会显示一个用 `Space` 切换的
`[ ] NULL` 复选框；清空文本字段写入的是空值，而不是 NULL。主键列会显示但不可
编辑：它们是更新语句所指向的地址。

## 编辑值

在单元格上按 `Enter` 即可就地编辑。单元格会变成带光标的文本字段；再次按 `Enter`
保存，`Escape` 放弃。未更改的值完全不会执行查询。输入的文本按该列的类型解释，
因此数值列存储的是数字，而不是作为文本的数字字符。

编辑需要一种能精确指定唯一一行的方式，因此只对带有**主键**的表可用。其他表上，
面板会如此提示而不是打开编辑器。每次编辑都是一条按该主键定位的单行 `UPDATE`；
如果服务器报告没有行被更改——该行已被删除，或其键已变化——面板会提示你刷新，
而不是假装编辑已生效。

## 分页

行按窗口获取；内存中只保留当前窗口，因此即使是非常大的表也保持流畅。越过窗口末尾
时会自动加载下一个窗口。总行数（考虑当前过滤）在后台计算，就绪后显示在状态栏中。

## 连接恢复

若数据库连接断开或查询致命失败，面板会弹出恢复对话框：**重新连接**
对同一 URL 开启新连接，**关闭面板**关闭查看器。按 `Esc` 关闭对话框并
保留最后的结果。面板不会自行重试，因此不会出现错误循环。

## 限制（当前）

- 只读——不支持编辑，不支持任意 SQL。
- 特殊列类型（JSON、数组、UUID、时间戳、无符号整数）在此版本中显示为空/`NULL`；
  常见标量类型完整显示。
- 当 URL 未指定数据库时支持选择数据库；模式选择（PostgreSQL）仍默认使用当前模式。
