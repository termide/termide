# HTML 预览

TermIDE 将 HTML 文件（`.html`、`.htm`）渲染为只读预览面板——文本伪图形，而非原始源码。它*不是*浏览器：作者的 CSS 和脚本会被忽略，布局是固定的「标签→样式」映射。

## 打开

- 在 `.html` 文件上按 **`F3`** — 打开渲染后的预览。
- **`Enter`** 或 **`F4`** — 在编辑器中打开原始源码（与任何文本文件一样）。

## 预览 ↔ 源码

预览和源码编辑器是同一文件的两种视图。在原地切换——面板被替换，而不是堆叠：

- **`Ctrl+E`**（可通过 `[viewer.keybindings] toggle_view` 配置）。
- 状态栏中可点击的 **`Edit`** 标签。

在预览中，`Edit: No` 表示你正在查看渲染后的文档；点击它（或按 `Ctrl+E`）会打开**可编辑**的源码。在源码编辑器中，同一开关返回预览。当源码有未保存的改动时，切回预览会被阻止——请先保存。

## 渲染内容

使用 `html5ever` 进行词法分析（无 DOM、无 CSS）并绘制为文本伪图形。受支持的标签子集映射为带样式的块和行内片段；**未知标签是透明的**——其内容仍会渲染。HTML 实体（`&amp;`、`&#39;`）会被解码；`<script>`、`<style>` 和文档 `<head>` 的内容会被丢弃。

- 标题 `<h1>`–`<h6>`（带 `#` 前缀标记、强调色、加粗）。
- 段落和块级容器（`<p>`、`<div>`、`<section>` 等），以空行分隔。
- 行内强调：`<b>`/`<strong>`、`<i>`/`<em>`、`<u>`、`<s>`/`<del>`，以及 `<kbd>`/`<mark>`（反显）。
- 行内 `<code>` 和 `<pre>` 代码块（原样保留）。
- 无序 `<ul>` 和有序 `<ol>` 列表；`<blockquote>` 带 `│` 前缀。
- `<table>`（带 `<thead>` 表头行）使用制表符边框绘制。
- `<a href>` 链接（下划线、可点击），`<img>` 显示为可点击的 `🖼` 图标，后跟 alt 文本。
- `<br>` 换行、`<hr>` 分割线，以及 `<details>`/`<summary>`（展开显示）。

同一引擎也渲染 [Markdown 预览](markdown.md) 中嵌入的 HTML。

## 导航、选择、链接

预览有一个可移动的光标并支持文本选择：

- `↑`/`↓`/`←`/`→`（或 `k`/`j`/`h`/`l`）— 移动光标。
- `PageUp`/`PageDown`（或 `Space`）— 上/下翻页；`Home`/`End` — 行首/行尾；`g`/`G` — 文档开头/结尾。
- 按住 **`Shift`** 移动，或**用鼠标拖拽**，以选择文本。
- **`Ctrl+A`** 选中整个文档。
- **`Ctrl+C`** 将选区（无选区时为光标所在行）复制到剪贴板。
- **`Ctrl+F`** 打开增量搜索；**`Ctrl+R`** 从磁盘重新加载文件。
- **`Ctrl+G`** 提示输入路径**或 `http(s)://` URL**，并在匹配的查看器（HTML、Markdown、图片或文本）中打开——可快速跳到同级文件，或对网页进行基本的文本模式浏览（见下文*获取 URL*）。
- 鼠标滚轮滚动。
- **跟随链接**——点击它，或将光标置于其上按 `Enter`。链接**在 termide 内**打开：已获取的（基于 URL 的）页面原地导航（相对链接相对页面 URL 解析），来自基于文件视图的网页链接在新查看器中打开，指向**图片**的链接在图片预览中打开。
- **在外部打开链接**——在光标下的链接上按 **`O`** 或 **`Alt+Enter`**，或 **`Alt+点击`** 它：网页地址在浏览器中打开，文件或图片在系统应用中打开，与文件管理器中的 `O`/`Alt+Enter` 相同。按键由 `[viewer.keybindings] open_external` 设置。（某些终端会自行占用 `Alt`/`Option`+点击；按键始终有效。）
- **`[` / `]`**（或 **`Backspace`** 后退）在已导航视图的页面历史中后退/前进。
- **锚点链接**（`#section`）在页面内跳转（到匹配的 `id`）；`page#section` 先导航到该页面再跳到锚点。

## 另存为 Markdown

**`Ctrl+S`** 或面板 `[≡]` 菜单中的 **将页面另存为 Markdown…** 通过“另存为”对话框将页面保存为 Markdown 文件。标题、列表、代码块、表格和链接都会保留，相对链接会根据页面 URL（本地页面则根据文件）转换为绝对链接。与阅读模式类似，若页面有 `<main>`（或唯一的 `<article>`），则只导出该部分，并省略导航、侧边栏、页脚、表单和脚本。默认文件名：本地页面取文件名，否则取页面 `<title>`，再否则取网站主机名。

## 获取 URL

**Windows ▸ Open…** 菜单项打开一个通用提示（一个易于发现的入口），可接受文件路径、目录、数据库 URL 或 `http(s)://` 地址；在任何面板中按 `Ctrl+G` 也是如此。`Ctrl+G` 配合 `http(s)://` 地址会立即打开一个查看器，在后台获取文档期间其标题显示旋转指示器和 URL，随后按 `Content-Type` 路由显示（HTML → 本查看器，Markdown → Markdown 查看器，图片 → 图片预览，其他文本 → 原样显示）。获取失败时错误显示在该查看器中；关闭查看器即放弃此次获取。获取是刻意受限的——这是一个阅读器，而非浏览器引擎：

- 仅 `http` 和 `https`；TLS 会被校验（不可关闭）。
- 15 秒超时；最多 5 次重定向，且 `https` 来源绝不会降级为 `http`。
- 超过 8 MiB 的响应会被拒绝。
- 嵌入资源**不会**被加载——`<img>` 仍是 `🖼` 图标，因此页面无法通过查看器「回家上报」。

已获取页面内的链接以**原地**方式跟随（`Enter`/点击），相对链接相对页面 URL 解析，`[`/`]`（或 `Backspace`）用于历史；在下一页到达之前当前页面保持不变，标题中显示旋转指示器和新 URL；`O`/`Alt+Enter`/`Alt+点击` 则在真实浏览器中打开链接。基于 URL 的视图不会随项目布局恢复。

基于文件的面板随项目布局保存，并在同一文件上重新打开。
