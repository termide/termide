# Markdown 预览

TermIDE 将 Markdown 文件（`.md`、`.markdown`）渲染为只读预览面板，而不是打开原始源码。

## 打开

- 在 `.md` 文件上按 **`F3`** — 打开渲染后的预览。
- **`Enter`** 或 **`F4`** — 在编辑器中打开原始源码（与任何文本文件一样）。

## 预览 ↔ 源码

预览和源码编辑器是同一文件的两种视图。在原地切换——面板被替换，而不是堆叠：

- **`Ctrl+E`**（可通过 `[viewer.keybindings] toggle_view` 配置）。
- 状态栏中可点击的 **`Edit`** 标签。

在预览中，`Edit: No` 表示你正在查看渲染后的文档；点击它（或按 `Ctrl+E`）会打开**可编辑**的源码。在源码编辑器中，同一开关返回预览。当源码有未保存的改动时，切回预览会被阻止——请先保存。

## 渲染内容

使用 `pulldown-cmark` 解析并绘制为文本伪图形：

- 标题（带 `#` 前缀标记、强调色、加粗）。
- 加粗、斜体、删除线和行内 `code`。
- 无序和有序列表，包括嵌套。
- 引用块，带 `│` 前缀。
- 围栏代码块，使用与编辑器相同的引擎进行语法高亮。
- 表格，使用制表符边框绘制。
- 水平分割线和链接（下划线、可点击）。
- 图片显示为可点击的 `🖼` 图标，后跟 alt 文本（不使用终端图形协议）。
- 嵌入的 ```` ```mermaid ```` 代码块，渲染为图表本身（文本伪图形）而非原始源码。不支持的图表类型回退为普通代码块高亮。关于独立的 `.mmd` 查看器和支持的图表类型列表，参见 [Mermaid 图表](mermaid.md)。
- 嵌入的 HTML——块级（`<p align>`、`<div>`、`<details>`/`<summary>`、`<table>`、`<img>`）和行内（`<kbd>`、`<b>`、`<sub>`、`<br>` 等）——通过与独立 [HTML 预览](html.md) 相同的引擎渲染，而不是显示为字面的尖括号文本。

## 导航、选择、链接

预览有一个可移动的光标并支持文本选择：

- `↑`/`↓`/`←`/`→`（或 `k`/`j`/`h`/`l`）— 移动光标。
- `PageUp`/`PageDown`（或 `Space`）— 上/下翻页；`Home`/`End` — 行首/行尾；`g`/`G` — 文档开头/结尾。
- 按住 **`Shift`** 移动，或**用鼠标拖拽**，以选择文本。
- **`Ctrl+C`** 将选区（无选区时为光标所在行）复制到剪贴板。
- **`Ctrl+F`** 搜索；**`Ctrl+R`** 从磁盘重新加载；**`Ctrl+G`** 在匹配的查看器中打开输入的路径或 `http(s)://` URL（URL 获取策略参见 [HTML 预览](html.md)）。
- 鼠标滚轮滚动。
- **跟随链接**（点击或 `Enter`）：网页链接默认在查看器中打开，图片链接在图片预览中打开，`#heading` 锚点在页面内跳转。`O` 在外部打开链接；`[`/`]` 为历史后退/前进。链接打开设置和获取策略参见 [HTML 预览](html.md)。

该面板在会话之间保持，并在同一文件上重新打开。
